# 旧日变奏曲（Variations of Yesterday）

[English](README.md)

> _他们说，只要机器不停，山就不会塌。_
>
> _但他们错了。前天寨里的铜钲被拆走了。今天太阳还没落山，空气里的死灰味从地里钻了出来。_
>
> _后面怎么办，我不知道。_

> _铁镐砸在石头上的回音不对，而且██又响起来了。_
>
> _如果你能够看到这个，**不要在余音未散时急敲，也别指望把山脉镇死。不要相信██上███。顺着水沟往上走，守住还在跳的那一段。**_

_沉滞的灰烬正在蔓延，下游的河水已经浑浊。_

_去看看吧，顺着水流逆流而上，在这片土地的旧日，到底发生了什么。_
