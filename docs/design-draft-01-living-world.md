## 0. 定位与创作原则

- **类型**：民俗恐怖**氛围** + 生态模拟 + ARG 碎片化叙事；恐怖只活在氛围层与钩子层，不进机制层（裁定见[札记 10](design-note-10-meta-trilogy-and-drift.md) §5）。世界本身是一个「活着的」动力学系统。
- **主题**：「实事求是 vs 盲目征服」——人类理性的狂妄在复杂生态系统面前遭受反噬。不做现实政治指涉。
- **虚构原则**：地名、民族、机构、仪式、物种全部原创虚构；不指涉任何真实地域或真实民族，时间线模糊为上世纪末。
- **玩家角色**：「调制者」——监测、理解并安抚这片土地；跨越阵营口径，联合动力学读数与关系因果推演，在既定历史和动力学约束内辨认可达未来并顺势而为（§4）。
- **标题诠释**：「Variations of Yesterday / 旧日变奏曲」——「昨日」既是档案中留存的过去，也是不断重演的动力学循环。

## 1. 动力学层

### 1.1 模型结构：快变量 + 慢变量

- **快子系统**：FitzHugh–Nagumo（FHN）可激发介质方程（状态 `dissonance` $v$ / `entrench` $w$，参数 `alpha` / `beta` / `epsilon`）。
- **慢子系统**：土地应力 `stress` $s \in [0, s_{\max}]$ 与灾变活动示踪量 `activity` $q$，通过参数耦合 $a(s, M)$ 驱动快系统跨越分岔点，同一状态向量内四维 RK4 同步积分；**维持度 `sustenance` $M$ 是第五慢变量**（菌网完整度，札记 06 §7.1），在每步 RK4 之后显式推进，不进 RK4 向量。

```
dv/dt = v - v³/3 - w + p
dw/dt = ε·(v + a(s, M) - b·w)                   ε=0.08, b=0.8
a(s, M) = a₀ - Δ·(1 - M) - k·s                  a₀=0.7, k=1.0, Δ=1.2

ds/dt = γ·(u - δ(s)·s - ρ·(c₀ + c) + η·q)       γ=0.01, ρ=1.0, η=1.0
δ(s)  = δ₀ / (1 + (s/s_h)²)                     δ₀=0.3, s_h=0.15
dq/dt = λ·(max(|v| - V, 0) - q)                 λ=0.2, V=1.8
dM/dt = r·M·(1 - M) - c_burn·max(s - s_T, 0)·M + D·∇²M
                                                r=1e-3, c_burn=4e-3, s_T=0.6
                                                （gameplay 配置；核心默认 r=c_burn=0 休眠）
s 截断于 0 ≤ s ≤ s_max (s_max=1.0)
```

由迹条件 $\operatorname{tr}(J) = 1 - v_c^2 - \varepsilon b = 0$ 得精确 Hopf 失稳点：$v_c \approx -0.9675$，$a_c \approx 0.4350$（对应 $s_c \approx 0.2650$）；三次曲线右膝烧毁边界为 $a_{\text{burnout}} = b\cdot\frac{2}{3} - 1 \approx -0.4667$（对应 $s \approx 1.1667$）。以上数值均按 $M=1$（即 $\Delta(1-M)=0$）计算。

**输入通道**：
- `u`：持续扰动输入（爆破、采掘等）；另支持单次应力直接注入 `injectStress`；
- `p`：快变量冲击通道（玩家核心操作通道，相位敏感）：
  - **α 突触脉冲**（离散事件：敲钟、点炮）：一次事件对应一个 `(面积, τ)` 脉冲 `p(t) = 面积·(t/τ²)·e^(−t/τ)`，峰值 `面积/(e·τ)` 落在起跳后 $\tau$（突触延迟）；
  - **常数保持**（连续输入/测试）：直接保持幅度；
- `c`：主动安抚（调制设施）；
- `c₀`：基线安抚（老寨钟声等残余维护）；
- `q`：灾变自激发项（滞后效应来源）；
- `M`：维持度（第五状态；叙事通道 `EventMsg.SetSustenance` 直接设定初值，之后由 `dM/dt` 自身演化，不是持续输入）。

### 1.2 核心动力学性质（见 `MandateStateSpec` / `PhaseResponseSpec`）

1. **阈值点火与自持（滞后效应）**：持续扰动越过宽容区后激发大幅张弛振荡；由于自激发项 $\eta q$ 与状态依赖恢复率 $\delta(s)$，撤除外部扰动 $u$ 后振荡仍自持（「停手不能止灾」），必须主动干预才能回到静息态。
2. **宽容区（Forgiving Zone）**：轻伤快愈、重伤难愈。存在宽容容量 $u^* = \max_s (\delta(s)s + \rho c_0)$（$c_0=0$ 时约 $0.0225$）。温和活动（$u < u^*$）永不点火；工业活动击穿宽容区。
   - **临界慢化**：接近宽容区边缘时扰动恢复变慢，构成前兆信号；
   - **基线安抚 $c_0$**：撑大宽容容量，拆钟/毁堰会导致安全余量缩水；
   - **阈下单次激发（预兆事件）**：静息态下强踢动触发单次孤立脉冲后自行回落；
   - **双通道反馈**：每次注入扰动伴随即时阈下视听响应，与延迟的真正灾变构成归因闭环。
3. **烧毁边界与通道拆分**：常规输入下 $s$ 截断于 $s_{\max}=1.0$（对应 $a = -0.30 > a_{\text{burnout}}$），仍在自持振荡窗口内。方程级烧毁态（`BurnoutNoCycle`）有两条路径：契约切片（$M=1$、M 动力学默认休眠）中只能由叙事通道抽走维持源触发（`EventMsg.SetSustenance`，见札记 06 §7.1）；gameplay 下 `VoyConfig` 默认启用 M 的酸蚀项，持续高应力亦可耗尽 M 进入深度失能（札记 06 §7.1 实测）。
4. **相位调制与占空比反转（Duty-Cycle Inversion）**：
   - 截面相位以 $v$ 上穿 $1.2$ 为相位 $0$；真实尖峰（相位传感口径）定义为「上穿截面且峰值 $\ge 1.8$ 后回落穿过 $0$」；读数层的尖峰标签为正向 $v \ge +1.8$（札记 08）。
   - **近临界起振区（$s = 0.30, a = 0.40$，周期 $T \approx 43.7$）**：去极化高台期（$v > 0$）仅占周期的 **28.1%**，周期中段（$\varphi = 0.50$）落在左支超极化恢复段，正向脉冲 `alpha_shock` 当场触发提前尖峰（`-17.38`）。
   - **饱和过驱动区（$s = 1.0, a = -0.30$，周期 $T \approx 39.5$）**：高台期膨胀至周期的 **60.6%**，$\varphi = 0.50$ 仍处上支高台期，正向脉冲反而延长平台期、产生强推迟（`+15.62`）。
   - **实测安全刻度（`safe_ticks`）**：金属共振脉冲（`alpha_metal_resonance`）在饱和振荡器上逐整数 tick 实测，仅将真实尖峰结果为 `Delayed` 的刻度写入跨栈契约 `contracts/mandate-slice-v1.json`，供叙事卷宗按种子绑定。
   - **诚实边界**：强负向脉冲（`-25`）会打入对侧大幅瞬态，不能作为熄灭工具；单次正向推迟只是争取窗口，不等于取消灾变。

### 1.3 空间离散：Node、区块格子场与休眠调度

> 状态：**设计已定（2026-11-07），实现待排期**——当前运行时仍是固定 32×32 平铺格子，Node 分组与调度事件尚未落地；方程与数值层不受本节影响。

- **Node ↔ Grid/Cell 分层**：Node 是生成期的稀疏容器锚点（一条支沟 / 一个聚落群的格子集合），不持有独立动力学状态；每个 Cell 持有一份 `MandateState`（四维 RK4 状态 + 显式积分的维持度 `M`）。
- **Node 拓扑**：世界生成时落若干组 Node；Node 内部由输运边（对称扩散 + 沿地势梯度的单向平流）连成局部格子场。Node 可以相邻并共享局地输运边（边界格互相影响），也可以远隔——远隔 Node 之间没有输运边，只走水晶 / 红石脉络（札记 07 的 `PulseLink`，事件层 `p` 通道脉冲；只传相位，不传应力；红石只在边界读写原版信号，札记 06 §2.3）。相邻 Node 的活动档位各自独立，因此允许出现「一侧细步、一侧粗步」的边界，按 1.3.4 的容差耦合处理。
- **最小调度单位为 Node**：节点内所有格子同速步进（节点内禁止异速）；Node 有两种调度档位——**活跃**（细步长 `dt`）与**静息**（粗步长 $K\cdot dt$）。所有 Node 始终在动力学图中（不依赖区块加载顺序），静息只降频、不脱管。
- **空间耦合**：Node 内格子图上的对称扩散（图拉普拉斯）与沿地势梯度的单向平流（`MandateGrid`）。

#### 1.3.1 静息判据与确定性调度

- **深静息判据**（同时满足才允许粗化）：Node 内全部 Cell 无周期（`Basin(Resting)` 或 `Undefined` 的非瞬态）、聚合 `Regime` 为 `Calm`、最近一个粗化窗口内无尖峰、该 Node 无在途脉冲、无待处理通道事件；连续满足 $N_{quiet}$ 个窗口后进入粗化，任一条件破坏立即回到细步长。
- **调度由 `simTime` 纯派生**：全局 tick 序号 $tickIndex = \operatorname{round}(simTime/dt)$；静息 Node 只在 $tickIndex \bmod K = 0$ 的 tick 积分，其余 tick 不改状态。因此不需要每节点步进累加器——重启后由存档 `simTime` + 恢复的 Node 状态即可重建同一调度（与现行「整格快照含 `simTime`」一致）。
- **步长上限与容差**：$K \in \{2,4,8\}$，默认 $K=4$（`dt=0.05` 时粗步长 0.2）；仅深静息 Node 允许 $K>2$。粗化不追求逐步数值等价，验收口径为：
  1. `Regime` 与 `PhaseReading` 分类不变——不得把 `Calm` 推成 `Strained`，不得产生或漏掉尖峰；
  2. 慢变量误差有界：同一参考窗口内 $|s_{\text{coarse}}-s_{\text{fine}}|$ 与 $|M_{\text{coarse}}-M_{\text{fine}}|$ 不超过 $\varepsilon_s$（先取 $10^{-2}$ 量级，由金样校准）；
  3. 玩家可见层（验山读数、HUD、感官签名）档位不变；
  4. 唤醒后的轨迹在容差内回到细步长参考（见 1.3.2）。
- **快照与持久化按 Node 增量**：Node 积分时才发布该 Node 的只读快照，游戏线程读取合并视图（`4e9b78b` 的既定决定「快照按节点增量发布」）；持久化保存全局 `simTime` + 各 Node 的 Cell 状态、通道电平、参数、边与链路，不保存调度计数器（由 `simTime` 与状态重建）。

#### 1.3.2 休眠期事件与唤醒

休眠 Node 的状态「停在最后一次粗积分」。因此**任何改变该 Node 的事件都必须先追平、再应用、再唤醒**，且全部在同一信箱全序内完成以保证确定性：

| 事件类别 | 处理 | 唤醒 |
| :--- | :--- | :--- |
| `TickArrived` | 仅调度到期的 Node 积分，其余 Node 保持状态 | 否 |
| 通道事件（`StressInject` / `SetDisturbance` / `SetCalming` / `SetBaselineCalming` / `HoldImpulse` / `FirePulse` / `SetSustenance`） | 先以细步长把 Node 从上次积分追平到当前 `simTime`（至多 $K-1$ 步），再应用事件，随后重置该 Node 的相位跟踪器 | **是** |
| 跨 Node 脉冲到达（`PulseLink` 排定的 `FirePulse`） | 按排定的 `fireAt` 精确处理：先把目标 Node 追平到 `fireAt`（不量化到粗边界），再应用脉冲；同 tick 多个脉冲按 `(Node, fireAt, 队列顺序)` 批处理 | **是** |
| 拓扑事件（`RegisterCell` / `RemoveCell` / `UpsertEdge` / `RemoveEdge` / `AddLink` / `RemoveLink`） | 立即改拓扑或布线，不动动力学状态；`RegisterCell` 的初值即该 Cell 在静息期的状态 | 否（新 Cell 落入活跃 Node 时随该 Node 步进） |
| `FlushNow`（保存前 flush） | 不追平、不唤醒：Node 状态在其最后积分 tick 上自洽，直接序列化最新快照 | 否 |
| 玩家接近 / 交互（接线层） | 发一个不进入动力学的调度事件（如 `ActivateNode`，需新增）；收到后追平 + 转细步长 | **是** |

- **「休眠了就不大可能有事件」成立**：采掘 / 敲钟 / 再接种等玩家事件都发生在附近 Node（`MandateOverworld` 只对已加载区块生效）；远处 Node 的入口只有三类例外——玩家远行或传送、跨 Node 脉冲、命令 / worldgen 拓扑回填，上表已覆盖。
- **唤醒滞回**：唤醒后保持细步长，直到重新满足 1.3.1 的深静息判据连续 $N_{quiet}$ 个窗口才可再次粗化；唤醒计数属于运行时簿记，不进存档（重启后最坏多活跃一个窗口，可接受）。
- **在途脉冲与相位**：追平按固定 `dt` 逐 tick 积分，走与活跃 Node 相同的代码路径，因此 `PhaseTracker` 的穿越插值与 `PulseLinkRunner` 的确认窗 / 延迟语义不变；Node 休眠期不推进相位跟踪器，唤醒时重置，避免用冻结状态算出错误的 `fraction`。
- **重放确定性**：调度、追平、唤醒全部由 `(simTime, 事件流, Node 状态)` 决定，不读墙钟；同一事件流重放会得到同一调度与同一粗细轨迹。

#### 1.3.3 明确不做（本机制范围）

- **离线加速风化**：服务器关闭期间仿真时间不推进，重启从存档 `simTime` 继续，不补算离线时长。
- **跨 Node 全局同步**：不要求相邻 Node 同步步进；跨界输运按 1.3.4 的容差耦合处理。
- **远隔 Node 之间的输运边**：没有共享边界的 Node 之间不得有输运边；worldgen 若产生，按拓扑事件规则丢弃并告警。
- **逐步数值等价**：以 1.3.1/1.3.4 的分类不变与误差界为准，不要求粗细轨迹逐位一致。

#### 1.3.4 不同活跃度 Node 的相邻边界（容差耦合）

相邻 Node 各自判定深静息，因此可能一条边界两侧一细一粗。跨界输运不要求同步步进，只要求误差有界：

- **细步侧**：每 tick 照常积分，粗步邻居取其**最后一次积分态**（滞后至多 $K\cdot dt$；深静息时邻格漂移可忽略）。
- **粗步侧**：每 tick 把跨界边的通量累加为 `pendingFlux`（`stressFlux` / `sustenanceFlux` 分开累计），粗步时以**窗口平均通量**（累计值 / $K$）参与积分——与现行「通量直接进 ds/dt」的语义一致。
- **唤醒与追平**：`pendingFlux` 或邻格活跃度超过阈值即唤醒；追平期间边界通量用最近 $K$ 个邻格状态重算（每边界格至多 $K$ 个 double，可忽略），或接受一次性小 kick（在容差内）。粗步档位变化（$K$ 变大）同样先追平再换档。
- **容差口径**：不要求两侧通量严格守恒；验收在 1.3.1 四条之外再加一条——长跑（$\ge 10^4$ sim 单位）无 `Regime` 漂移、无伪尖峰、跨界两侧应力差不超过 $\varepsilon_s$。
- **保守模式（第一版建议）**：与任何非深静息 Node 相邻的 Node 暂不粗化（等价于按边连通簇同档），先保证零混合边界；混合边界金样通过后再默认启用容差模式。两种模式共用同一套静息判据，只是调度策略不同。

### 1.4 语义化读数投影与调度接口

- **读数投影层（`MandateReadout`）**：呈现层不直接读取裸浮点数，统一通过 `ReadoutParam` 映射为：
  - **慢变量分级（`Regime`）**：`Calm` / `Strained` / `Oscillating` / `Burnout`；
  - **快变量相位读数（`PhaseReading`）**：周期轨道 `Cycle(label, fraction)`（四相标签 `Excitation` / `AbsoluteRefractory` / `RelativeRefractory` / `Resting` 及 20 格刻度 `dialTick`）、静息域 `Basin(Resting)`、无周期 `Undefined(BurnoutNoCycle | TransientNoCycle | NoCycleReference)`。
- **Tick 事件驱动调度**：`END_SERVER_TICK` 投递固定步长 `TickArrived(dt = 0.05, tickRate)` 进入引擎单线程 actor（`inner/actor` 内核上的 `MandateAgent`），与通道事件（`StressInject` / `SetDisturbance` / `SetCalming` / `SetBaselineCalming` / `HoldImpulse` / `FirePulse` / `SetSustenance`）、拓扑事件（`RegisterCell` / `RemoveCell` / `UpsertEdge` / `RemoveEdge` / `AddLink` / `RemoveLink`）及持久化控制 `FlushNow` 同信箱全序处理，仿真时间恒等于游戏时间。无玩家在线时不投递 tick。游戏线程只读 `@volatile` 快照（`MandateRuntime`）并在下一 tick 消费动作回包（`MandateOverworld`）。

## 2. 地势与谷地：因果的方向

- **有向平流**：在扩散图上沿地势梯度加有向边（高 $\rightarrow$ 低），扰动顺沟而下，形成「下游聚落受灾 $\rightarrow$ 沿沟上溯定位源头工程」的可溯源因果链。
- **物候与土法监测**：慢变量表现为谷雾、异响、水体浑浊度；快变量四相绑定物候与 1980s 土法监测器具（验山簧片、铅锤垂架、钟表/指南针读数），让世界本身充当仪表盘。
- **Worldgen 约束**：梯度图由区块高度图经 D8 汇流算法推导缓存，不依赖原版河流生物群系。Node 自然边界优先取分水岭/山脊线。

## 3. 聚落与玩家动机

### 3.1 寨与村
- **老寨（共同体）**：有边界、有镇山古器（铜钲/分水石堰），提供基线安抚 $c_0$，居民作息对土地应力敏感；不注册为原版村庄，采用以物易物/礼物经济交换档案线索。
- **垦殖分场/宿舍区（行政化改制）**：古器被收缴或拆毁（$c_0 = 0$），对应力反应迟钝。
- **制度演进骨架**：山官火塘共议 $\rightarrow$ 清丈触及与「外甲内寨」妥协 $\rightarrow$ 垦殖总场改组与工程进山 $\rightarrow$ 撤场后「场部—议事会」双轨制或封山/回流（详见札记 02 §5「地形组合与可达性」）。

### 3.2 沉滞（Stagnation）与心跳维持闭环
> 2026-11-08 按札记 08 定稿修订：沉滞来源由「无 $c_0$」改为「无脉冲保鲜窗」，$c_0$ 与沉滞解耦。
> 2026-11-09 再裁定：沉滞的咬合面从玩家身体回归 2026-09-28 定稿的**原版经济**（动机闭环），玩家身体只在尖峰/过载时承担。
- **沉滞的来源是「太久没有脉冲」**：一次有效正脉冲（敲钟 / 水晶链路；尖峰吞没的 `SpikeSwallowed` 一击只进方程、不计心跳）为区块开启抵消窗（默认约一个自然振荡周期 ≈40 s，随耐受递减）；窗内主动解除 `voy:stagnation`，窗外每 20 tick 重新施加。
- **沉滞压在原版经济上**：无庇护区块内交易加价（special price +2，尖峰期 +5）、村民繁殖/铁傀儡召唤/作物随机刻生长按 keep 概率被吞（基线 0.5 / 尖峰 0.25 量级，数值见 `MandatePhenomena.EconomyProfile`，钩子走 mixin 层 `VillagerEntityMixin` / `CropBlockMixin`）；村民以 `voy:stagnation` 标记 + 环境粒子显形。**格子场外的休眠区按 `CellReadout.zero` 判为沉滞**——「谷外安全但贫瘠」由修辞落地为字面机制。
- **玩家身体只在急性档承担**：基础档不碰玩家（标记只给村民显形，「这块地没有庇护」由经济与村民状态表达）；尖峰爆发/饱和失能期玩家才吃 `voy:stagnation_spike`（挖掘 ×0.09）与缓慢、灰烬粒子（见 `MandateEffects` / `MandateOverworld`）。
- **脉冲过密即过载烧毁**：间隔小于安全窗（默认 8 s）或耐受饱和的脉冲把细胞顶进急性 `BurnoutNoCycle`（去极化阻滞），抵消窗作废，敲钟者即刻吃 `voy:pulse_saturation`（挖掘 ×0.75、移速 ×0.85），且耐受加深使后续抵消窗缩短——刷钟会把自己锁进无法靠敲钟脱身的沉滞。
- $c_0$ 退居慢变量安抚通道（`-ρc₀` 项）与感官签名庇护条件（菌光/前兆孢子，札记 06 §3），不再提供沉滞免疫。维持生存 = 维持地脉的心跳节律与菌网健康；盲目采掘击穿宽容区 → 酸蚀耗菌 → 慢性菌竭烧毁（`M → 0`），届时敲钟毫无回音，只能泄压后再接种。

## 4. ARG 叙事与双模型主线

- **叙事知识 = 机制优势**：档案中的实测推迟刻度、器物编号与流转批号由世界种子在生成时填入（`Voy.World.Witness`），对抗 Wiki 剧透。
