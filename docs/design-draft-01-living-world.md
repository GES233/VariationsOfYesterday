# 设计草案 01 — 活着的世界：动力学、河流、聚落与叙事

> 状态：草案（讨论固化稿，非最终实现承诺）。
> 本文档取代旧概念稿（星象/草药等，已废弃）。

## 0. 定位与创作原则

- **类型**：中式民俗恐怖 + ARG 碎片化叙事 + 生态模拟。世界本身是一个「活着的」动力学系统。
- **主题**：「实事求是 vs 盲目征服」——人类理性的狂妄在复杂生态系统面前遭受反噬。不做现实政治指涉。
- **虚构原则**：地名、民族、机构、仪式全部原创虚构（风格上接近滇西南山区，但不使用真实地名与真实民族）。所有叙事元素不指涉真实群体与真实历史事件；时间线模糊为「上世纪末」。
- **玩家角色**：不是征服者，而是「调制者」——监测、理解并安抚这片土地。

## 1. 动力学层（骨）

### 1.1 模型结构：快变量 + 慢变量

- 沿用现有 `MandateState` 的 FitzHugh–Nagumo 方程组作为**快子系统**（状态 `dissonance`/`entrench`，参数 `alpha/beta/epsilon`）。FHN 是 Hodgkin–Huxley 的二维简化，属「可激发介质」一族，天然具备双稳态特性。
- 新增**慢变量**：土地应力 `stress s ≥ 0`。它不作为新的 ODE 维度直接积分进快系统，而是通过**参数耦合**驱动 FHN 跨越失稳点。

### 1.1.1 耦合形式（已经数值实验验证，2026-09）

快子系统（与 `MandateState` 现有方程完全一致）：

```
dv/dt = v - v³/3 - w
dw/dt = ε·(v + a(s) - b·w)        ε=0.08, b=0.8
a(s)  = a₀ - k·s                  a₀=0.7, k=1.0
```

应力把恢复零线（w-nullcline）推向三次曲线中段：理论 Hopf 失稳点 a_c≈0.467（s_c≈0.233）；慢斜坡下存在**慢通过效应**（slow-passage），实际点火延迟到 s≈0.42。

慢子系统：

```
ds/dt = γ·(u - δ·s - ρ·c + η·q)   γ=0.01, δ=0.05, ρ=1.0, η=1.0
dq/dt = λ·(max(|v| - V, 0) - q)   λ=0.2, V=1.8（尖峰阈值）
s 截断于 0 ≤ s ≤ s_max（s_max=1.0，见 §1.1.2 第 5 条）
```

- `u`：扰动输入（玩家爆破/采掘等事件的应力注入）；
- `c`：主动安抚（仪式/调制装置），**这是玩家的核心操作通道**；
- `q`：灾变活动示踪量——灾变自身回馈应力（自激发项 `η·q`），这是滞后效应的结构来源。

### 1.1.2 数值验证结论（Python/RK4，脚本与图在 `build/tmp/fhn_stress_experiment.*`）

1. **阈值点火**：持续扰动下应力积累，跨越 s≈0.42 后快系统从静息突变为大幅张弛振荡（|v|≈2），突变是跳跃式的（类 canard 爆发），不是渐变；
2. **自持**：扰动撤为零后振荡不停止（自激发项维持 s≈0.65，远高于下折点）——「停手不能止灾」；
3. **滞后**：平息灾变必须主动安抚，把应力压到远低于点火阈值（实验中 c=0.10 将 s 压向 0，振荡在 4 次余波后停止且不再复发）；
4. 点火阈值 s↑≈0.42，熄灭阈值 s↓≈0.36（准静态意义），但真正的滞后体现在控制量 `u` 上：点火需 u≈0.05 持续，自持态在 u=0 依然存活；
5. **应力必须是有界指标**（Scala 实现时发现）：`δ(s)` 状态依赖恢复 + 自激发会使 s 冲过振荡窗口（a(s) < -0.467），不动点滑到三次曲线右支，系统进入「烧毁」式饱和死寂——应力很高却不再振荡，破坏自持设计。故 s 截断于 s_max=1.0（仍在振荡窗口内）。（「烧毁态」本身有叙事潜力——过度激怒后土地死寂而非狂暴——留作后续设计素材。）

滞后效应（hysteresis）由此成为玩法第一公理：灾变跨越临界点后，把应力降回原值不足以平息系统，必须主动干预压到安全区。这构成玩家的核心生存压力。

### 1.1.3 平缓期保障与早期游戏节奏（已经数值实验验证，2026-09）

**静息态是渐进稳定吸引子**：阈下扰动指数衰减（快环回落 τ≈5，随后慢流形漂移 τ~1/ε）。「土地受到小扰动后自行平复」是方程内禀性质，无需额外机制。

**宽容区（forgiving zone）**：恢复率改为状态依赖——轻伤快愈、重伤难愈：

```
ds/dt = γ·(u - δ(s)·s - ρ·(c₀ + c) + η·q)
δ(s)  = δ₀ / (1 + (s/s_h)²)            δ₀=0.3, s_h=0.15
c₀    ≥ 0  基线安抚（村庄钟仪式等残余维护）
```

存在宽容容量 `u* = max_s (δ(s)·s + ρc₀)`（c₀=0 时 ≈0.0225）：持续扰动低于 u* 时应力停在低平衡态**永不点火**；高于 u* 时低平衡态消失，应力逃逸点火。早期/中期分界因此是硬性的：温和活动（手工/小农作，u 小）永远安全，工业活动（爆破/深采，u 大）击穿宽容区。不按游戏阶段硬编码，只按活动赋 u 值，难度曲线从方程自然涌现。

三个派生设计点：

- **临界慢化（critical slowing down）**：接近宽容区边缘时扰动恢复变慢，构成玩家可观测的前兆信号（如「这次水体变浑后三天才清」）；
- **基线安抚 c₀**：残存仪式（村庄钟）撑大宽容容量；村庄衰落/钟被拆 → 安全余量悄然缩水——「保护伞在玩家不知情时被撤掉」；
- **阈下单次激发（预兆事件）**：可激发介质性质——远低于点火阈值时，单次大踢动（雷击/TNT）触发一次孤立激变脉冲后自行回落。用于早期游戏的恐怖但无害的「怪事」，零额外机制。

参考框架：Scheffer 浅水湖泊双稳态模型、云杉卷叶蛾爆发模型（Holling）；理论读物见 §6。

### 1.2 空间离散：区块粒度格子场

- 应力场以**每区块一个标量**存储（16m 分辨率），视距 10 时约 441–2500 个活跃格子；可进一步降为 2×2/4×4 区块一格（32–64m 分辨率）。
- 空间耦合：格子图上的**扩散**（图拉普拉斯）。格子间邻接关系静态。
- 异质性来自**静态系数**而非模拟世界：生物群系、高度、河流、玩家建造物作为外力项/参数空间分布注入方程。
- **绝不逐方块模拟**（量级差 4 个数量级，不可行）。

### 1.3 扰动注入

- 玩家行为与事件（爆破、采掘、水利建设、装置运行、降雨等）以 `EventDTO` 形式进入模拟层，转化为局部应力增减或参数扰动。
- 模拟输出经 `MandateActionProtocol` 返回游戏层（生成事件、天气、AI 扰动等）。
- 保持现有分层：模拟核心不触碰 Minecraft 游戏上下文。

### 1.4 性能预算与工程原则

- FHN + 拉普拉斯扩散在 2500 格子、1Hz 模拟频率、20 子步下约百万级 flops/s，**算力不是瓶颈**。
- 真正的成本原则是**不碰世界**：模拟循环不读方块、不发方块更新；格子状态经 `PersistentState` 按维度持久化。
- **慢变量慢着算**：模拟频率 1Hz 起步即可；系统深处于静息吸引域时自适应降频，接近临界点时加密。
- 模拟运行于 Pekko actor 独立 dispatcher：游戏线程只投递事件、消费快照，不在主线程积分。
- 数值注意：显式扩散格式受 CFL 条件约束（D·Δt/Δx² ≤ 1/2）；生态时间尺度 Δt 偏大时需调小扩散系数或扩散项半隐式化。

### 1.5 已知缺陷备忘

- `MandateAgent.simulationLoop` 子步进 bug：循环内 `solver.update(oldState.state, dt)` 始终从旧状态出发，N 个子步实为重复同一步而非推进 N 步。慢变量改造时一并修复。

## 2. 河流：因果的方向

### 2.1 平流-扩散

- 在扩散图上为河流经过的格子间加**有向边**（上游→下游权重高，逆流弱或无），即拉普拉斯矩阵非对称化。算力成本几乎不变。
- 玩法效果：扰动顺流而下，形成**可溯源的因果链**——下游村庄遭殃 → 溯河找到上游的坝/矿洞/被炸开的山体。与 ARG「读档案 → 实地验证」节奏咬合。

### 2.2 河流作为慢变量仪表

- 水位、流速、水质（水体颜色/粒子/渔获丰度）反映上游应力状态。
- 玩家学会「看水识山」后无需 GUI 数值面板——世界本身就是仪表盘。

### 2.3 水利 = 调制基础设施

- 玩家调制装置依水而建：水车、导流渠、拦河堰。
- 叙事点：玩家最终会发现自己建造的工程与档案中图纸的拓扑同构——「农业水利复合工程 = 仪式」在玩法层面重现。

### 2.4 Worldgen 现实（重要约束）

- Vanilla（1.18+）地形是噪声函数；**河流不是数据结构**，是河谷 carve + river 群系的涌现结果，无上下游/流向元数据；水位基本贴海平面，不能可靠地用高度推流向。
- 因此流向图需**自行推导**：区块粒度高度图 + river 群系/水体检测，跑 D8 汇流算法（每格指向最低邻居），首次加载时计算并缓存。大尺度与视觉河道吻合，小尺度有出入，可接受。
- Vanilla 村庄与河流**无几何关联**（不沿河生成）。

## 3. 聚落：信号与代价

### 3.1 生物指示器（前震信号）

- 应力接近临界点时，村庄内村民行为微妙失序：作息紊乱、拒绝上床、无由聚集、钟被敲响。
- 实现方向：village AI 外挂一层由邻近格子应力驱动的行为扰动，不改写村民 AI 本体。

### 3.2 钟：失传仪式的残片

- 村庄钟的敲击习俗设定为古老祭祀的残片，具有微弱镇定效果（小幅降低周围格子的应激增益）。
- 叙事弧：前期玩家以为是迷信 → 后期破译档案发现钟声频率落在方程抑制区间 → 用红石定时敲钟。**科学复刻巫术，点题**。

### 3.3 代价的具象化

- 灾变爆发时，抽象数值经由村庄变为具体损失：作物枯死、牲畜死亡、村民「失踪」（呼应 ARG 档案中的「自然损耗」统计）。
- 滞后效应的情感重量由此而来：应力降回后灾变停止，但村庄不可逆地改变。

### 3.4 空间结构（目标形态）

- 山区水系为树状：支流汇干流，村庄沿河分布，整图因果拓扑是一棵**有向树**——源头深山（工程遗迹）→ 下游聚落（玩家）。ARG 探索动线、灾变传播路径、档案地名链同构于这棵树。
- 受 worldgen 限制，此为目标形态，见 §5 路线分级。

## 4. ARG 叙事层（皮肉）

### 4.1 核心原则：叙事知识 = 机制优势

- Lore 不是收集品。读懂档案 = 操作得更好：档案中的日期规律 = 调制装置安全运行窗口；被涂改的电路图还原后 = 装置合法构型。
- ARG 线与探索线互为表里：破译文档推进玩法，玩法瓶颈逼玩家翻文档。

### 4.2 碎片载体（按实现成本排序）

1. 成书/书与笔——档案、报表、会议记录主力载体；
2. 物品重命名 + lore——搪瓷缸、工作证、测绘手簿等时代小物；
3. 自定义唱片——广播录音、警报、磁带（呼应「声学复刻咒语」设定）；
4. 地图物品——官方测绘图与实际地形的偏差本身是谎言的物证；
5. 结构生成——废弃测绘站、水文站、导流渠遗迹，箱子战利品表分发文档；
6. Advancements——改造为玩家的「调查板」；
7. 世界本身——空间畸变是「祂」留下的、最后才被学会阅读的档案。

### 4.3 文档分层（防剧透结构）

- 表层：口吻刻板的行政文书，化名、代号、统计口径；
- 中层：矛盾——涂改、批注、两份文件数字对不上；
- 深层：玩家自行拼出「工程图纸走向 = 仪式拓扑」。

### 4.4 文档圣经（先行产物）

- ARG 乐趣来自内部一致性：代号、文号、日期、单位必须可交叉印证。
- 动工前先在 `docs/` 写「文档圣经」：虚构地名表、机构表、人物表、代号体系、时间线。所有游戏内文档从它派生。

## 5. Worldgen 路线分级

- **路线 A（原型阶段采用）**：不动 worldgen，应力场/流向图/村庄检测全部运行时推导。兼容任意存档，工程量最小；代价是视觉河道与模拟图小尺度出入、村庄布局随缘、叙事舞台不可控。
- **路线 B（中期目标）**：自定义 world preset / dimension（「河谷」世界类型），以主河谷为骨架设计群系分布，自撒村庄与遗迹。数据驱动（JSON density function / biome / structure set），不写 chunk generator。
- **路线 C（不做）**：自定义 chunk generator。工程量最大、兼容性最差，除非 B 证明不够用。

玩法核心（格子场 + 平流 + 村庄指示器）在路线 A 下全部可验证；worldgen 定制是叙事包装层升级，不是玩法前置依赖。
