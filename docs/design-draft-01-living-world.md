## 0. 定位与创作原则

- **类型**：中式民俗恐怖 + ARG 碎片化叙事 + 生态模拟。世界本身是一个「活着的」动力学系统。
- **主题**：「实事求是 vs 盲目征服」——人类理性的狂妄在复杂生态系统面前遭受反噬。不做现实政治指涉。
- **虚构原则**：地名、民族、机构、仪式全部原创虚构（风格上接近滇西南山区，但不使用真实地名与真实民族）。所有叙事元素不指涉真实群体与真实历史事件；时间线模糊为「上世纪末」。
- **玩家角色**：不是征服者，而是「调制者」——监测、理解并安抚这片土地。
- **标题诠释**：「Variations of Yesterday / 旧日变奏曲」沿用不改。「昨日」双关：既是档案中留存的过去（玩家在昨日里翻找真相），也是一个命题——昨日从未过去，它只是不断重演。变奏的具体内容与清单由叙事设计另行确定，不列入本文档。

## 1. 动力学层（骨）

> **0.1 结构冻结声明（2026-09-27）**：本章的方程组结构、通道语义、格子场架构、加载不变性原则、相位调制与 α 突触脉冲结构**冻结**——实现期间不改结构，只调参数（`γ/δ₀/s_h/ρ/η/λ/τ/窗口位置/u*` 等全部保持可调）。解冻条件：纵切片（§8）中产生了机制无法回答的玩法问题，或数值验证与本文结论矛盾。冻结范围不包括：慢通道 α（§1.1.4 标注的后续扩展）、c 的习惯化（防塌缩的候选方向）、§7 列明的开放问题。

### 1.1 模型结构：快变量 + 慢变量

- 沿用现有 `MandateState` 的 FitzHugh–Nagumo 方程组作为**快子系统**（状态 `dissonance`/`entrench`，参数 `alpha/beta/epsilon`）。FHN 是 Hodgkin–Huxley 的二维简化，属「可激发介质」一族，天然具备双稳态特性。
- 新增**慢变量**：土地应力 `stress s ≥ 0`。它不作为新的 ODE 维度直接积分进快系统，而是通过**参数耦合**驱动 FHN 跨越失稳点。

### 1.1.1 耦合形式（已经数值实验验证，2026-09）

快子系统（与 `MandateState` 现有方程完全一致）：

```
dv/dt = v - v³/3 - w + p
dw/dt = ε·(v + a(s) - b·w)        ε=0.08, b=0.8
a(s)  = a₀ - k·s                  a₀=0.7, k=1.0
```

应力把恢复零线（w-nullcline）推向三次曲线中段：理论 Hopf 失稳点 a_c≈0.467（s_c≈0.233）；实际点火还受输入路径和慢通过效应（slow-passage）影响，因此不把单次实验中的点火应力当作固定阈值。

慢子系统：

```
ds/dt = γ·(u - δ(s)·s - ρ·(c₀ + c) + η·q)   γ=0.01, ρ=1.0, η=1.0
δ(s)  = δ₀ / (1 + (s/s_h)²)                    δ₀=0.3, s_h=0.15
dq/dt = λ·(max(|v| - V, 0) - q)                λ=0.2, V=1.8（尖峰阈值）
s 截断于 0 ≤ s ≤ s_max（s_max=1.0，见 §1.1.2 第 5 条）
```

- `u`：扰动输入（玩家爆破/采掘等事件的应力注入）；
- `p`：快变量冲击通道，两种形态，**这是玩家的核心操作通道**——效果依赖相位，见 §1.1.4：
  - **α 突触脉冲**（离散游戏事件：敲钟、雷击、单次爆破）：一次事件 = 一个 `(面积, τ)` 脉冲（`firePulse(area)`），内核为双指数级联 `p(t) = 面积·(t/τ²)·e^(−t/τ)`，峰值 `面积/(e·τ)` 落在起跳后 τ（突触延迟）；
  - **常数保持**（连续输入：装置持续运转、调试指令）：直接保持幅度，用于稳态强迫与测试；
- `c`：主动安抚（仪式/调制装置的残余镇静效应），慢方程减项；注意单独的常驻 c 目前可以零代价永久稳定系统（深度塌缩风险，见 §1.1.4 的防塌缩设计）；
- `c₀`：基线安抚（聚落或长期维护产生的残余保护）；
- `q`：灾变活动示踪量——灾变自身回馈应力（自激发项 `η·q`），这是滞后效应的结构来源。

### 1.1.2 数值验证结论（Scala/RK4，回归测试见 `MandateStateSpec`）

这里只记录当前实现可直接复现的行为，不沿用已经丢失实验条件的历史数值：

1. **阈值点火**：`u=0.05` 的持续扰动在早期保持静息，随后进入重复的大幅张弛振荡；测试要求 500 时间单位内无尖峰、6000 时间单位内至少出现 5 次尖峰且应力超过 0.4；
2. **自持**：`u=0.08` 的有限时脉冲结束后，振荡仍能长期持续——「停手不能止灾」；
3. **主动熄灭**：自持阶段施加 `c=0.10` 的有限时安抚后，系统回到低应力区，并在安抚撤去后保持静息；测试要求末段无复发且最终 `s<0.05`；
4. **宽容区**：`u=0.01` 持续 8000 时间单位不触发尖峰，最终保持 `s<0.1`；
5. **应力必须是有界指标**（Scala 实现时发现）：`δ(s)` 状态依赖恢复 + 自激发会使 s 冲过振荡窗口（a(s) < -0.467），不动点滑到三次曲线右支，系统进入「烧毁」式饱和死寂——应力很高却不再振荡，破坏自持设计。故 s 截断于 s_max=1.0（仍在振荡窗口内）。**通道拆分**：玩家可达的常规输入（u/c/p）永远到不了烧毁态，截断保护保留；烧毁态只由叙事参数通道制造——局部调高耦合系数 k，或专用「强制镇压」输入把 s 推过截断窗口（见 §4.5 湮灭）。「烧毁态」由此保持「湮灭是方程的吸引子，不是修辞」，同时不破坏自持设计。

滞后效应（hysteresis）由此成为玩法第一公理：灾变跨越临界点后，把应力降回原值不足以平息系统，必须主动干预压到安全区。这构成玩家的核心生存压力。

### 1.1.3 平缓期保障与早期游戏节奏（已经数值实验验证，2026-09）

**静息态是渐进稳定吸引子**：阈下扰动指数衰减（快环回落 τ≈5，随后慢流形漂移 τ~1/ε）。「土地受到小扰动后自行平复」是方程内禀性质，无需额外机制。

**宽容区（forgiving zone）**：恢复率改为状态依赖——轻伤快愈、重伤难愈：

```
ds/dt = γ·(u - δ(s)·s - ρ·(c₀ + c) + η·q)
δ(s)  = δ₀ / (1 + (s/s_h)²)            δ₀=0.3, s_h=0.15
c₀    ≥ 0  基线安抚（村庄钟仪式等残余维护）
```

存在宽容容量 `u* = max_s (δ(s)·s + ρc₀)`（c₀=0 时 ≈0.0225）：持续扰动低于 u* 时应力停在低平衡态**永不点火**；高于 u* 时低平衡态消失，应力逃逸点火。早期/中期分界因此是硬性的：温和活动（手工/小农作，u 小）永远安全，工业活动（爆破/深采，u 大）击穿宽容区。不按游戏阶段硬编码，只按活动赋 u 值，难度曲线从方程自然涌现。

三个派生设计点：

- **临界慢化（critical slowing down）**：接近宽容区边缘时扰动恢复变慢，构成玩家可观测的前兆信号（如「这次水体变浑后三天才清」）；
- **基线安抚 c₀**：残存仪式（村庄钟）撑大宽容容量；村庄衰落/钟被拆 → 安全余量悄然缩水——「保护伞在玩家不知情时被撤掉」；
- **阈下单次激发（预兆事件）**：可激发介质性质——远低于点火阈值时，单次大踢动（雷击/TNT）触发一次孤立激变脉冲后自行回落。用于早期游戏的恐怖但无害的「怪事」，零额外机制。
- **双通道反馈（归因保障）**：灾变延迟会切断「行为 → 后果」的学习链，因此每次注入 u 都伴随即时、局部、无害的阈下响应（远处闷响、水面涟漪、村民同时转头），与延迟出现在下游的真正灾变组成双通道；溯源由河流因果链（§2.1）提供。同时须尽早确定 **1 时间单位 ↔ 游戏/现实时间** 的映射并写成设计目标，例如「普通玩家首次真正灾变发生在第 3–5 小时」，接入时按此反推参数——现有参数为数值验证所选，不是节奏参数。

参考框架：Scheffer 浅水湖泊双稳态模型、云杉卷叶蛾爆发模型（Holling）；理论读物见 §6。

### 1.1.4 相位调制：时机就是机制（2026-09 数值预实验验证）

`p(t)` 是对快变量 v 的冲击通道。离散游戏事件走 **α 突触脉冲**（一次事件 = 一个 `(面积, τ)` 脉冲，内核 `p(t) = 面积·(t/τ²)·e^(−t/τ)`，峰值 `面积/(e·τ)` 落在起跳后 τ——「突触延迟」，τ 即该事件类型的响应滞后，入档案）；连续输入走常数保持。可激发介质的内禀性质：**同一刺激落在不同相位，结果完全不同**。

预实验结论（自持振荡区 `u=0.05`，尖峰周期 T≈39.5 时间单位；相位 0 = 尖峰上升沿越过 v≈1.2；α 脉冲峰值归一到与矩形冲击相同）：

- **易损窗口**：尖峰后约 **40%–60% 周期**——冲击当场激发一次提前的完整尖峰（提前量 ≈ 冲击所在相位本身）；
- **不应期早期（≲35%）与恢复晚期（≳65%）**：冲击基本被吸收，周期变化 ≤2–4%；
- **α 通道的相位依赖符号（τ=5 时）**：不应期中早期（约 20–30% 周期）的脉冲**推迟**下一次尖峰（间隔最多约 **+8.6** 时间单位，τ 越大推迟越长：τ=10 时达 **+20**；2026-09-28 用 `PhaseModulationSpec` 同款装置复测确认符号为正、数值吻合），易损窗口内点火，恢复晚期无效——**同一脉冲是压一波还是点一把，由相位决定**，「调制」一词至此名副其实；
- τ 越大窗口边缘越软（τ=2 时窗口近似矩形、 onset 锚定；τ=10 时推迟区显著展宽）——τ 是事件类型的「惯性」，也是难度调参的天然旋钮。

设计含义：

- 敲钟/装置脉冲的**时机**即核心技巧；档案中「日期规律 = 安全运行窗口」从比喻变成字面机制——读懂档案的人知道什么时候敲，**敲错了就是亲手点火，敲早了只是暂时压住**（推迟不等于取消，压力仍在积累）；
- 「突触延迟」给呈现层一个可教的常数：玩家学到「钟响后约 τ 土地才应」，把操作时机换算成仪式口诀；
- 「科学复刻巫术」（§3.2）获得机制内核：村民仪式的价值不在钟本身，在节律；
- 慢通道侧（对 `s` 的 α 脉冲，τ 大 1–2 个数量级）作为后续扩展：事件尾部拖长叠加，自然产生「积少成多」的慢性压力；原型阶段先只做快通道。

诚实边界（预实验同时证伪/削弱的设想）：

- 负向「压制」脉冲在现参数下**不是可靠的熄灭工具**：强反向冲击把轨迹打入对侧大幅度瞬态，且 q 按 |v| 计——镇压本身成为扰动（恰好是叙事中总指挥部命运的数值镜像，可作叙事素材，不作操作机制）；相位推迟效应部分替代了「熄灭」的游戏功能，但**推迟不是取消**，灾情会顺延而非消散；
- 恰落在上升沿的脉冲可跳过当次尖峰，但窗口窄、对数值步进对齐敏感——列为调参项，不写入承诺。

防塌缩（与 §二.3 外部评审意见对齐）：常驻 `c` 作为纯减项 + s 截断于 0，目前允许一个足够强的常驻安抚装置永久稳定系统。组合方向：`p` 升为核心通道后，给 `c` 加**习惯化**（同一装置反复使用效果递减）或物资消耗；原型阶段先验证 `p` 单独是否已足够好玩，再决定 `c` 的削弱幅度。

回归测试：`PhaseModulationSpec`（矩形：易损窗口点火 / 不应期吸收 / 恢复晚期吸收 / 静息单次激发后回落；α：内核形状（峰值时刻与高度、面积守恒）/ 易损窗口点火 / 不应期推迟）。

### 1.2 空间离散：区块粒度格子场

- 模拟采用 **Node ↔ Grid/Cell** 分层：Node 只承载区域级慢变量，Grid/Cell 承载局部空间差异与快变量；格子以区块或 2×2/4×4 区块为一格，具体分辨率后续按表现与性能确定。
- 世界创建时按种子确定有限数量的潜在 Node；Mandate Cell 不随普通探索自动扩张，新增 Cell/Node 需要明确的物品、仪式或协议。实际游玩规模以全世界一万格以内为目标，因此已转化状态可脱离 Minecraft 区块加载而常驻数值模拟。
- Vanilla Cell 不进入动力学图，也不是 `stress=0` 的吸收边界；只有 Mandate Cell 之间存在空间耦合。扩散/连边本身不负责扩张，跨区域传播需要显式协议边。**动力学边界必须在呈现层可感知**（声景、粒子、生物行为的渐进变化），否则「同样的操作，这里出事那里不出事」会造成归因困惑。
- 空间耦合：格子图上的**扩散**（图拉普拉斯）与协议允许的有向运输。每个世界坐标至多对应一份 Cell 状态，聚落和 Node 对同一空间场施加影响，不各自复制一份重叠 Grid。
- 异质性来自**静态系数**而非模拟世界：生物群系、高度、河流、玩家建造物作为外力项/参数空间分布注入方程。
- **绝不逐方块模拟**（量级差 4 个数量级，不可行）。

### 1.3 扰动注入

- 玩家行为与事件（爆破、采掘、水利建设、装置运行、降雨等）以 `EventDTO` 形式进入模拟层，转化为局部应力增减或参数扰动。
- 模拟输出经 `MandateActionProtocol` 返回游戏层（生成事件、天气、AI 扰动等）。
- 保持现有分层：模拟核心不触碰 Minecraft 游戏上下文。

### 1.4 性能预算与工程原则

- FHN + 拉普拉斯扩散在 2500 格子、1Hz 模拟频率、20 子步下约百万级 flops/s，**算力不是瓶颈**。
- 真正的成本原则是**不碰世界**：模拟循环不读方块、不发方块更新；格子状态经 `PersistentState` 按维度持久化。
- **加载不变性**：区块加载/卸载只决定能否采集世界输入和呈现结果，不改变 Node/Cell 身份、积分方程或邻接拓扑。相同外部事件在不同视距与加载顺序下应得到相同的动力学结果。
- **慢变量慢着算**：模拟频率 1Hz 起步即可；系统深处于静息吸引域时自适应降频，接近临界点时加密。
- 模拟运行于 Pekko actor 独立 dispatcher：游戏线程只投递事件、消费快照，不在主线程积分。
- 数值注意：显式扩散格式受 CFL 条件约束（D·Δt/Δx² ≤ 1/2）；生态时间尺度 Δt 偏大时需调小扩散系数或扩散项半隐式化。
- **调度语义（2026-09-28 实现决定，补充 §1.4 既有原则、不改方程结构）**：模拟节拍由 Pekko actor 自定（`scheduleWithFixedDelay` 于独立 dispatcher），积分 deltaTime 一律由 nanoTime 实算；server tick 事件退化为「世界运行状态」的 gate 与 `/tick rate` 变更通知（`TickArrived`/`TickSpeedUpdate`，见 `EventMsg`），不再逐 tick 驱动积分。tick 速率变化时 actor 侧自适应两个维度——节奏（调度间隔/积分预算）与步长（`dt` 可随加速放大，白名单只过**数值稳定性**：CFL 与应力截断；**相位保真不设防**——高速 tick 下相位窗口漂移是玩家主动放弃精细调控的固有代价，呈现层以此为叙事素材：「加速流逝 = 风化」，钟不准、读数不可信是应得后果，不视为缺陷）。积分预算设 catch-up 上限，超出丢弃盈余并记日志。

## 2. 河流：因果的方向

### 2.1 平流-扩散

- 在扩散图上为河流经过的格子间加**有向边**（上游→下游权重高，逆流弱或无），即拉普拉斯矩阵非对称化。算力成本几乎不变。
- 玩法效果：扰动顺流而下，形成**可溯源的因果链**——下游村庄遭殃 → 溯河找到上游的坝/矿洞/被炸开的山体。与 ARG「读档案 → 实地验证」节奏咬合。

### 2.2 河流作为慢变量仪表

- 水位、流速、水质（水体颜色/粒子/渔获丰度）反映上游应力状态。
- 玩家学会「看水识山」后无需 GUI 数值面板——世界本身就是仪表盘。

### 2.3 水利 = 调制基础设施

- 玩家调制装置依水而建：水车、导流渠、拦河堰。
- 叙事点：玩家最终会发现自己建造的工程与档案中图纸的拓扑同构——「农业水利复合工程 = 仪式」在玩法层面重现。

### 2.4 Worldgen 现实（重要约束）

- Vanilla（1.18+）地形是噪声函数；**河流不是数据结构**，是河谷 carve + river 群系的涌现结果，无上下游/流向元数据；水位基本贴海平面，不能可靠地用高度推流向。
- 因此流向图需**自行推导**：区块粒度高度图 + river 群系/水体检测，跑 D8 汇流算法（每格指向最低邻居），首次加载时计算并缓存。大尺度与视觉河道吻合，小尺度有出入，可接受。
- Vanilla 村庄与河流**无几何关联**（不沿河生成）。

## 3. 聚落：信号与代价

### 3.1 生物指示器（前震信号）

- 应力接近临界点时，村庄内村民行为微妙失序：作息紊乱、拒绝上床、无由聚集、钟被敲响。
- 实现方向：village AI 外挂一层由邻近格子应力驱动的行为扰动，不改写村民 AI 本体。

### 3.2 钟：失传仪式的残片

- 村庄钟的敲击习俗设定为古老祭祀的残片，具有微弱镇定效果（小幅降低周围格子的应激增益）。
- 叙事弧：前期玩家以为是迷信 → 后期破译档案发现钟声频率落在方程抑制区间 → 用红石定时敲钟。**科学复刻巫术，点题**。

### 3.3 代价的具象化

- 灾变爆发时，抽象数值经由村庄变为具体损失：作物枯死、牲畜死亡、村民「失踪」（呼应 ARG 档案中的「自然损耗」统计）。
- 滞后效应的情感重量由此而来：应力降回后灾变停止，但村庄不可逆地改变。

### 3.4 空间结构（目标形态）

- 山区水系为树状：支流汇干流，聚落沿河分布，整图因果拓扑是一棵**有向树**——源头深山（工程遗迹）→ 下游聚落（玩家）。ARG 探索动线、灾变传播路径、档案地名链同构于这棵树。
- 受 worldgen 限制，此为目标形态，见 §5 路线分级。

当前收敛方向（只作为后续实现约束）：

- 世界创建时按种子确定少量大型 Branch/地域的逻辑中心与潜在 Node 布局；这里只生成规划，不为远处选址强制加载区块，实际结构在相关区块生成时落地并持久化最终坐标。
- 每个 Branch 内安排若干距离相近的寨子节点，为合作、资源竞争和争斗提供初始拓扑；Branch 是生成与叙事骨架，不必形成不可穿越的硬边界。
- 寨子节点保留稳定身份；所谓独立、合并或分裂优先表现为关系/共同体成员变化，不销毁原节点及其历史状态。
- 预留有限的潜在建寨位置供玩家尝试建立新节点；这是受条件约束的机会，不保证一定成功，也不意味着普通探索会自动扩张 Mandate 区域。

### 3.5 寨与村：两种聚落类型

- **核心区分**：村是行政/经济单元（开放、无边界、权力外置）；寨是血缘-防卫-祭祀共同体（有寨墙寨门、有头人/祭司、有集体仪式空间、有成员资格、共同体经济）。
- **「寨变成村」本身就是故事**：上世纪的行政化改造把寨改制成村，头人被干部取代、仪式空间改作他用——仪式不是被「禁止」消失的，是随组织形式解体而失传的。安抚功能寄生于寨的共同体结构，结构没了，泄压阀就没了。
- **机制映射**：
  - **寨（残存）**：有边界、有钟（仪式器物的残片，形制原创虚构，不用真实民族器物）、提供基线安抚 c₀、居民对土地应力敏感（生物指示器 §3.1）；
  - **村/农场宿舍区（行政化）**：无边界、无钟、**不提供 c₀**、对应力反应迟钝。玩家会直觉发现「老寨子那边不太平的事少」——不靠档案也能传达的叙事。
- **反刷分设计**：寨**不注册为 vanilla village**（不走 vanilla 的 POI/钟认领/袭击触发逻辑），无铁傀儡生成机制、无绿宝石交易经济——刷铁机/劫掠塔的底层钩子整个不存在。交换改为礼物经济/以物易物：向寨子「缴纳」换取信任与档案线索（头人/账房保管旧文书 = ARG 碎片分发渠道）。
- **路线 B 下**：vanilla 村庄结构不生成，全部由寨取代；vanilla 村民机制整体弃用。
- **政治发展历程骨架**（报告写作用）：头人制 →（虚构的流官改制与编户制的触及和失败）→ 工程队进山 → 撤场后的（虚构）场部—议事会时代（附带偶发的旧生产关系回流）。每一步组织形式更替对应一份不同口径的报告。制度一律用虚构名称（与 §0 虚构原则对齐），只保留结构；正式名称由文档圣经定名。

## 4. ARG 叙事层（皮肉）

### 4.1 核心原则：叙事知识 = 机制优势

- Lore 不是收集品。读懂档案 = 操作得更好：档案中的日期规律 = 调制装置安全运行窗口（相位窗口，见 §1.1.4）；被涂改的电路图还原后 = 装置合法构型。
- **知识本地化（对抗 wiki 消解）**：关键数值——安全窗口、钟声节律、代号对应的坐标——由世界种子在生成档案时填入；玩家在网上能学到「怎么读」，但每个世界里「读出来是什么」必须亲自去读。这本身也是主题演绎：没有放之四海皆准的答案，只有实事求是。
- ARG 线与探索线互为表里：破译文档推进玩法，玩法瓶颈逼玩家翻文档。

### 4.2 碎片载体（按实现成本排序）

1. 成书/书与笔——档案、报表、会议记录主力载体；
2. 物品重命名 + lore——搪瓷缸、工作证、测绘手簿等时代小物；
3. 自定义唱片——广播录音、警报、磁带（呼应「声学复刻咒语」设定）；
4. 地图物品——官方测绘图与实际地形的偏差本身是谎言的物证；
5. 结构生成——废弃测绘站、水文站、导流渠遗迹，箱子战利品表分发文档；
6. Advancements——改造为玩家的「调查板」；
7. 世界本身——空间畸变是「祂」留下的、最后才被学会阅读的档案。

### 4.3 文档分层（防剧透结构）

- 表层：口吻刻板的行政文书，化名、代号、统计口径；
- 中层：矛盾——涂改、批注、两份文件数字对不上；
- 深层：玩家自行拼出「工程图纸走向 = 仪式拓扑」。

### 4.4 文档圣经（先行产物）

- ARG 乐趣来自内部一致性：代号、文号、日期、单位必须可交叉印证。
- 动工前先在 `docs/` 写「文档圣经」：虚构地名表、机构表、人物表、代号体系、时间线。所有游戏内文档从它派生。
- 实操形态：用户手写若干篇虚构「调查报告」（`docs/lore/`）作为设定源文件，设计从中派生。

### 4.5 主体的下落（草案，待细化）

工程主体的结局为三分结构（纯幻想框架，无现实指向）：

- **飞升（总指挥部核心，小部分人）→ 末地**：以极端空间畸变自我放逐，「变成安德」（末影人化）。机制锚点：
  - 征用 vanilla 末影人做叙事：搬方块 = 永恒的施工；被直视即暴怒 = 知道真相者惩罚「注视」；瞬移 = 应力畸变的空间裂隙；
  - 填充 §5.0 末地（机制真空的死地）为「飞升者的放逐地」，终局彩蛋；
  - 可选钩子：主世界游荡的末影人搬动河处方块时注入微小应力扰动（「回来的安德」作为叙事内生的随机 u 事件源）。
- **湮灭（大部分人）→ 烧毁态区块**：总指挥部强行超大规模镇压 → 局部应力冲穿阈值 → §1.1.2 第 5 条的烧毁态成为空间实体：灰白变异材质的绝对死寂区块，无怪物无机制，只有静止。湮灭是方程的吸引子，不是修辞。机制通道：烧毁态**只**由叙事参数通道制造（局部调高耦合系数 k，或专用「强制镇压」输入把 s 推过 s_max 截断窗口）——它是「总指挥部做过的事」的物证，而不是玩家失误可以到达的状态。数值注脚：预实验显示强反向冲击本身会把轨迹打入对侧大幅度瞬态（q 按 |v| 计）——「镇压制造更大的乱子」在方程内成立，正是湮灭线的力学隐喻。
- **同化（项目基层，一部分）→ 新寨民**：补给断绝、灾变爆发后，农场职工退化重拾曾被批判的仪式（§3.5 的倒错版）：劳保服、被供奉的报废拖拉机、公文腔的《祭祀流程》。其余人消失。
  - 由此「寨」有二层来源：原生老寨（仪式残片）vs 退化新寨（工程残骸变异的仪式），两者档案口径互相矛盾 = ARG 中层素材。

## 5. Worldgen 路线分级

- **路线 A（原型阶段采用）**：不动 worldgen，应力场/流向图/村庄检测全部运行时推导。兼容任意存档，工程量最小；代价是视觉河道与模拟图小尺度出入、村庄布局随缘、叙事舞台不可控。
- **路线 A+（原型即可用）**：不动地形，仅通过 datapack 的 structure set 加入寨、水文站、导流渠遗迹等结构——不需要自定义 world preset 就能获得叙事舞台，补上路线 A 下「寨从哪里来」的悬空；兼容性成本接近路线 A。
- **路线 B（中期目标）**：自定义 world preset / dimension（「河谷」世界类型），以主河谷为骨架设计群系分布，自撒村庄与遗迹。数据驱动（JSON density function / biome / structure set），不写 chunk generator。
- **路线 C（不做）**：自定义 chunk generator。工程量最大、兼容性最差，除非 B 证明不够用。

玩法核心（格子场 + 平流 + 村庄指示器）在路线 A 下全部可验证；worldgen 定制是叙事包装层升级，不是玩法前置依赖。

### 5.0 领地性原则（跨层级决策）

「祂」是有领地的：叙事与机制都不铺满无限世界，「只有这片山区是活的」是设定核心（否则工程队为何偏偏来此）。世界分三层：

- **河谷（活的、有叙事的）**：应力场活跃区。实现上应力场积分逻辑全局通用，但慢变量耦合系数按地域分布——河谷（断裂带/矿脉等虚构地质理由）显著，远离河谷衰减至零；远处格子整体休眠，顺带解决性能；
- **主世界其余（普通的、机制休眠的）**：无叙事的普通 MC，不需要解释——公文有管辖范围，「本报告调查范围为 ×× 河流域」即收编无限世界。边界感是真实感，不是破绽；
- **下界（死的、机制真空的）**：不 ban。祂不在那里——监测装备进下界完全无读数，「连被安抚的资格都没有」的死地；「安全」本身成为反向的恐怖。档案可留一笔「工程队曾试图在此寻找什么，一无所获」；
- **末地（叙事边缘）**：不硬融。故事模式下末地门以废墟形态存在，档案留语焉不详的彩蛋，不进主线；有好点子再启用。

## 8. 0.1 版本定义（纵切片）

> 结构冻结后的第一个可玩目标：**一条河、三个寨、一种调制装置、十份档案**。先证明核心循环（扰动 → 前兆 → 灾变 → 溯源 → 相位调制）好玩，再谈扩展。

**范围内（验收标准）：**

1. **动力学接入**：格子场按维度持久化（`PersistentState`）；模拟在 Pekko actor 独立 dispatcher 运行；加载不变性有验证（相同事件序列在不同加载顺序下结果一致）；1Hz 起步 + 静息自适应降频；
2. **河流因果链**：D8 流向推导与缓存；扰动顺流传播可玩——下游遭殃、溯流找到上游源头；
3. **聚落**：三个寨经 datapack structure set 落地（路线 A+）；寨提供 c₀、不注册为 vanilla village；生物指示器最低限度实现（应力驱动的村民作息/聚集异常）；
4. **调制装置**：钟/红石脉冲映射为 α 突触脉冲（快通道，面积/τ 初版参数）；相位窗口（点火/推迟/无效）在呈现层可感知；开发 HUD 保留；
5. **边界可感知**：进入/离开 Mandate 活区有最低限度的前兆性呈现（声景或粒子或生物行为之一）；
6. **叙事最小集**：文档圣经骨架（地名/机构/代号/时间线）；十份档案可收集且内部一致；关键数值（安全窗口、钟声节律）按世界种子填入；
7. **时间尺度**：1 时间单位 ↔ 游戏时间映射确定并写入；按「首次真正灾变第 3–5 小时」反调校准；
8. **双通道反馈**：每次扰动伴随即时、局部、无害的阈下响应（闷响/涟漪/村民齐转头之一）。

**范围外（0.1 不做）**：宏观进程线与结局（§7.7）、多人规则（§7.6）、玩家动机设计（§7.8）、末地/下界叙事（§4.5/§5.0）、慢通道 α、习惯化、路线 B worldgen、退化新寨。

**0.1 的检验**：找一个不读文档的人玩两小时——能否察觉「这地方不对劲」，并把某次灾变和自己的某个行为联系起来（评审 §三.5 的标准）。不能，则问题在可读性呈现层，而非再加机制。
