# 设计草案 01 — 活着的世界：动力学、地势、聚落与叙事

> 状态：**0.1 结构冻结**。
>
> 方程组结构、通道语义、格子场架构、加载不变性原则、相位调制与 α 突触脉冲结构保持稳定，实现期间只调参数。

## 0. 定位与创作原则

- **类型**：中式民俗恐怖 + ARG 碎片化叙事 + 生态模拟。世界本身是一个「活着的」动力学系统。
- **主题**：「实事求是 vs 盲目征服」——人类理性的狂妄在复杂生态系统面前遭受反噬。不做现实政治指涉。
- **虚构原则**：地名、民族、机构、仪式全部原创虚构（风格接近滇西南山区，不使用真实地名与真实民族，时间线模糊为上世纪末）。
- **玩家角色**：「调制者」——监测、理解并安抚这片土地；跨越阵营口径，联合动力学读数与关系因果推演，在既定历史和动力学约束内辨认可达未来并顺势而为（§4.6）。
- **标题诠释**：「Variations of Yesterday / 旧日变奏曲」——「昨日」既是档案中留存的过去，也是不断重演的动力学循环。

## 1. 动力学层

### 1.1 模型结构：快变量 + 慢变量

- **快子系统**：FitzHugh–Nagumo（FHN）可激发介质方程（状态 `dissonance` $v$ / `entrench` $w$，参数 `alpha` / `beta` / `epsilon`）。
- **慢子系统**：土地应力 `stress` $s \in [0, s_{\max}]$ 与灾变活动示踪量 `activity` $q$，通过参数耦合 $a(s)$ 驱动快系统跨越分岔点，同一状态向量内四维 RK4 同步积分。

```
dv/dt = v - v³/3 - w + p
dw/dt = ε·(v + a(s) - b·w)                      ε=0.08, b=0.8
a(s)  = a₀ - k·s                                a₀=0.7, k=1.0

ds/dt = γ·(u - δ(s)·s - ρ·(c₀ + c) + η·q)       γ=0.01, ρ=1.0, η=1.0
δ(s)  = δ₀ / (1 + (s/s_h)²)                     δ₀=0.3, s_h=0.15
dq/dt = λ·(max(|v| - V, 0) - q)                 λ=0.2, V=1.8
s 截断于 0 ≤ s ≤ s_max (s_max=1.0)
```

由迹条件 $\operatorname{tr}(J) = 1 - v_c^2 - \varepsilon b = 0$ 得精确 Hopf 失稳点：$v_c \approx -0.9675$，$a_c \approx 0.4350$（对应 $s_c \approx 0.2650$）；三次曲线右膝烧毁边界为 $a_{\text{burnout}} = b\cdot\frac{2}{3} - 1 \approx -0.4667$（对应 $s \approx 1.1667$）。

**输入通道**：
- `u`：持续扰动输入（爆破、采掘等）；另支持单次应力直接注入 `injectStress`；
- `p`：快变量冲击通道（玩家核心操作通道，相位敏感）：
  - **α 突触脉冲**（离散事件：敲钟、点炮）：一次事件对应一个 `(面积, τ)` 脉冲 `p(t) = 面积·(t/τ²)·e^(−t/τ)`，峰值 `面积/(e·τ)` 落在起跳后 $\tau$（突触延迟）；
  - **常数保持**（连续输入/测试）：直接保持幅度；
- `c`：主动安抚（调制设施）；
- `c₀`：基线安抚（老寨钟声等残余维护）；
- `q`：灾变自激发项（滞后效应来源）。

### 1.2 核心动力学性质（见 `MandateStateSpec` / `PhaseResponseSpec`）

1. **阈值点火与自持（滞后效应）**：持续扰动越过宽容区后激发大幅张弛振荡；由于自激发项 $\eta q$ 与状态依赖恢复率 $\delta(s)$，撤除外部扰动 $u$ 后振荡仍自持（「停手不能止灾」），必须主动干预才能回到静息态。
2. **宽容区（Forgiving Zone）**：轻伤快愈、重伤难愈。存在宽容容量 $u^* = \max_s (\delta(s)s + \rho c_0)$（$c_0=0$ 时约 $0.0225$）。温和活动（$u < u^*$）永不点火；工业活动击穿宽容区。
   - **临界慢化**：接近宽容区边缘时扰动恢复变慢，构成前兆信号；
   - **基线安抚 $c_0$**：撑大宽容容量，拆钟/毁堰会导致安全余量缩水；
   - **阈下单次激发（预兆事件）**：静息态下强踢动触发单次孤立脉冲后自行回落；
   - **双通道反馈**：每次注入扰动伴随即时阈下视听响应，与延迟的真正灾变构成归因闭环。
3. **烧毁边界与通道拆分**：常规输入下 $s$ 截断于 $s_{\max}=1.0$（对应 $a = -0.30 > a_{\text{burnout}}$），仍在自持振荡窗口内；方程级烧毁态（`BurnoutNoCycle`）仅由叙事参数通道（如调高耦合系数 $k$）触发。
4. **相位调制与占空比反转（Duty-Cycle Inversion）**：
   - 截面相位以 $v$ 上穿 $1.2$ 为相位 $0$；真实尖峰定义为「上穿截面且峰值 $\ge 1.8$ 后回落穿过 $0$」。
   - **近临界起振区（$s = 0.30, a = 0.40$，周期 $T \approx 43.7$）**：去极化高台期（$v > 0$）仅占周期的 **28.1%**，周期中段（$\varphi = 0.50$）落在左支超极化恢复段，正向脉冲 `alpha_shock` 当场触发提前尖峰（`-17.38`）。
   - **饱和过驱动区（$s = 1.0, a = -0.30$，周期 $T \approx 39.5$）**：高台期膨胀至周期的 **60.6%**，$\varphi = 0.50$ 仍处上支高台期，正向脉冲反而延长平台期、产生强推迟（`+15.62`）。
   - **实测安全刻度（`safe_ticks`）**：金属共振脉冲（`alpha_metal_resonance`）在饱和振荡器上逐整数 tick 实测，仅将真实尖峰结果为 `Delayed` 的刻度写入跨栈契约 `contracts/mandate-slice-v1.json`，供叙事卷宗按种子绑定。
   - **诚实边界**：强负向脉冲（`-25`）会打入对侧大幅瞬态，不能作为熄灭工具；单次正向推迟只是争取窗口，不等于取消灾变。

### 1.3 空间离散：Node 与区块格子场

- **Node ↔ Grid/Cell 分层**：Node 是生成期的稀疏容器锚点，不持有独立动力学状态；每个 Cell 持有一份四维 `MandateState`。
- **最小激活与调度单位为 Node**：区域内任一 Cell 激活时，整个 Node 的 Cell 原子建模；未激活区域不进入动力学图。节点内所有格子同速步进，静息时按节点聚合状态做确定性 tick 抽稀降频。
- **空间耦合**：格子图上的对称扩散（图拉普拉斯）与沿地势梯度的单向平流（`MandateGrid`）。

### 1.4 语义化读数投影与调度接口

- **读数投影层（`MandateReadout`）**：呈现层不直接读取裸浮点数，统一通过 `ReadoutParam` 映射为：
  - **慢变量分级（`Regime`）**：`Calm` / `Strained` / `Oscillating` / `Burnout`；
  - **快变量相位读数（`PhaseReading`）**：周期轨道 `Cycle(label, fraction)`（四相标签 `Excitation` / `AbsoluteRefractory` / `RelativeRefractory` / `Resting` 及 20 格刻度 `dialTick`）、静息域 `Basin(Resting)`、无周期 `Undefined(BurnoutNoCycle | TransientNoCycle | NoCycleReference)`。
- **Tick 事件驱动调度**：`END_SERVER_TICK` 投递固定步长 `TickArrived(dt = 0.05, tickRate)` 进入 Pekko actor（`MandateAgent`），与通道事件（`StressInject` / `SetDisturbance` / `SetCalming` / `SetBaselineCalming` / `HoldImpulse` / `FirePulse`）同信箱全序处理，仿真时间恒等于游戏时间。无玩家在线时不投递 tick。游戏线程只读 `@volatile` 快照（`MandateRuntime`）并在下一 tick 消费动作回包（`MandateOverworld`）。

## 2. 地势与谷地：因果的方向

- **有向平流**：在扩散图上沿地势梯度加有向边（高 $\rightarrow$ 低），扰动顺沟而下，形成「下游聚落受灾 $\rightarrow$ 沿沟上溯定位源头工程」的可溯源因果链。
- **物候与土法监测**：慢变量表现为谷雾、异响、水体浑浊度；快变量四相绑定物候与 1980s 土法监测器具（验山簧片、铅锤垂架、钟表/指南针读数），让世界本身充当仪表盘。
- **Worldgen 约束**：梯度图由区块高度图经 D8 汇流算法推导缓存，不依赖原版河流生物群系。Node 自然边界优先取分水岭/山脊线。

## 3. 聚落与玩家动机

### 3.1 寨与村
- **老寨（共同体）**：有边界、有镇山古器（铜钲/分水石堰），提供基线安抚 $c_0$，居民作息对土地应力敏感；不注册为原版村庄，采用以物易物/礼物经济交换档案线索。
- **垦殖分场/宿舍区（行政化改制）**：古器被收缴或拆毁（$c_0 = 0$），对应力反应迟钝。
- **制度演进骨架**：山官火塘共议 $\rightarrow$ 清丈触及与「外甲内寨」妥协 $\rightarrow$ 垦殖总场改组与工程进山 $\rightarrow$ 撤场后「场部—议事会」双轨制或封山/回流（详见设计札记 02/04）。

### 3.2 原版沉滞（Stagnation）与维持源闭环
- 无有效 $c_0$ 维持源覆盖（或处于尖峰爆发/烧毁失效期）的区块，对玩家与周边原版村民施加「沉滞」负面状态（挖掘疲劳、缓慢与灰烬粒子，见 `MandateOverworld`）。
- 维持土地稳定与 $c_0$ 庇护 = 维持自身生产与生存环境；盲目工业采掘击穿宽容区会导致维持源周期性失效。

## 4. ARG 叙事与双模型主线

- **叙事知识 = 机制优势**：档案中的实测推迟刻度、器物编号与流转批号由世界种子在生成时填入（`Voy.World.Witness`），对抗 Wiki 剧透。
- **五跳局部证据链**：故事不写进任何单张全知摘要，而是拆分为五份局部单据（旧志先例 $\rightarrow$ 收缴/代管单 $\rightarrow$ 车间配料卡 $\rightarrow$ 野外观测手簿 $\rightarrow$ 现行条规）加两份同车间干扰单据，靠共享桥接元组合一还原（详见设计札记 03/05）。
- **历史结局与运行时分账**：
  - 世界生成时的六种历史结局（同化新寨、烧毁死寂区、空间裂隙、幸存对照、慢性渗漏、虚警耐受）是玩家入场前的既定事实；
  - 玩家通过跨阵营观测反演隐藏解释（`Ascribe` / `Observation`），在既有动力学约束下介入并由 Mandate 结算运行时结果（`Facts`）。
- **领地性原则**：仅目标山区谷地为活跃 Node；主世界其余区域休眠；下界为机制真空的死地；末地为空间裂隙飞升者的边缘彩蛋。

## 5. Worldgen 路线分级

- **路线 A（当前原型）**：不动地形，运行时网格 + 主世界方块/钟交互接线（`MandateRuntime` + `MandateOverworld`）。
- **路线 A+（近期目标）**：通过 datapack structure set 投放寨、钻探台、隘口木架与档案战利品。
- **路线 B（中期目标）**：数据驱动的自定义山区 world preset。
