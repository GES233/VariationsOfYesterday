# 设计札记 09 — 制式验山盘：有限域约束弛豫仪（定针/游核、同相互耗与盘契约）

> 状态：**设计合流稿（2026-11-08），未实施**。本稿由两轮跨 Agent 交叉审阅收口，分歧已全部裁定（路线甲：限定盘族 + 编纂期契约验证）。承接札记 07 §7 第 5 条「微网格（8×8 晶盘）」待办，但形态已从「自由布线晶盘」收敛为**制式验山仪器**；旧称「可编程晶盘」仅作档案留存。本札记不动四维 RK4 方程与 `contracts/mandate-slice-v1.json` 数值契约（克制原则同札记 07 §4）。

## 0. 一句话

水文队背进深山的「验山盘」是一台**制式有限域约束弛豫仪**：玩家把实测与卷宗钉成定针、把未知数放成游核，盘面靠「同相牵引（`==`）」与「同相互耗（`neq`）」两条离散脉冲原语弛豫到唯一驻波解——**仪器负责推理，大山负责阅卷**。

---

## 1. 定位：四层栈中的「仪器层」

诚实命名先行：盘面**不是通用 Kanren 机**——无递归、无无穷域、无答案流，跑不了 `appendo`；它是**有限域约束满足（CSP）的物理弛豫盘**，恰好够承载 24 候选反演（札记 02 §3）。四层各归各位，互不冒充：

| 层级 | 载体 | 数学本质 | 1980s 叙事包装 |
| :--- | :--- | :--- | :--- |
| **1. 编纂层** | Elixir `Voy.Kanren`（`tools/voy_world`） | 完整关系编程：递归、合一、`neq/2`、`Ascribe.abduceo/4` 生成 24 候选空间与五跳证据图 | jar 内 `.ex` 源码 = 水工队技术员留下的「推理机形式化手稿」（ARG 拆包彩蛋，见 §6） |
| **2. 仪器层（本札记）** | Scala 离散 GH 元胞机 + 游离晶核（盘内独立小实例） | 有限域 CSP / 耦合振荡器弛豫：锁相即 `==`，同相互耗即 `neq` | 「卢基扬诺夫式水力-压电验山盘」：把三方残缺卷宗（Hop 1–4）插进盘缘、观哪条支路驻波不灭来反演真凶与对时刻度的步进仪器 |
| **3. 换能薄桥层** | 谐振水晶（读）+ 发射水晶（写） | A/D 与 D/A：区块连续相位/σ/M ↔ 离散脉冲/红石 0–15 档，复用 `EventDTO` | 埋入地脉露头的压电收发探针与铜钲桩 |
| **4. 本体层** | Scala `MandateGrid` + `PulseCoupling`（区块大网） | 四维连续 FHN + 慢变量滞后 + Arnold 舌锁相 + 心跳抵消窗（札记 07/08） | 大山与活体菌网本身：连续、缓慢、**真实代价唯一发生地** |

### 1.1 仪器层内部：通用组件 + 模组物品

仪器层按「通用弛豫组件 + 具体物品绑定」拆分，**组件本身与大山无任何关联**：

- **通用组件（`inner/dial/`，纯 Scala，不 import Mandate/Minecraft）**：盘族定义（槽道几何、孔位、相位槽数 `K`）、定针/游核/导轨/分水桥元件、GH 三态步进器、弛豫运行器、盘契约（`dial-board-v1.json`）校验与存活域投影。它是一台通用的有限域约束弛豫机，只认识「变量、域、约束、解」。
- **模组物品（验山盘）**：把通用组件绑到世界——定针读数来自验山（钟表/指南针）、盘契约由 24 候选空间在编纂期生成、合闸经发射水晶向 `MandateRuntime` 投 `FirePulse`。山的关联全部住在这一层。

这不是投机性泛化：穷举契约验证的对象本来就是**通用机器**（与山无关，才有封闭可穷举的状态空间）；第二个消费场景是否存在留给后续，本札记不为假想物品预留 API。

## 2. 史料锚点与灵感谱系

- **卢基扬诺夫水力积分器（1936，苏联）**：以连通管水头求解偏微分方程，最初即用于土工/水文地质问题（坝体渗流、冻土裂隙）——「编程 = 接管子，运行 = 开水阀，读数 = 看水位」，与 1980s 山区水文地质工程设定严丝合缝。
- **MONIAC（1949，Phillips）**：水力模拟国民经济的同类机器，佐证「模拟计算机 = 组织元器件 + 施加外部动力」的两步工作流。
- **FORCEDENTRY（CVE-2021-30860）**：在非可编程介质（JBIG2 解码器）中以受限原语（位图 AND/OR/XOR/XNOR）自举出通用计算机。可迁移的不是漏洞本身，而是其结构：**宿主免费求值、原语组合封闭、无控制流全展开、计算价值由写回点定义**。验山盘沿用同一骨架：玩家排布盘面（组织元器件）→ 敲钟/链路激励（施加动力）→ 引擎弛豫求值（宿主免费计算）→ 合闸写回真实区块（写回点）。

## 3. 盘面物理：两条原语，零损耗试错

### 3.1 元件词表（永不暴露门）

盘面词表全部是仪器/民俗词，绝不出现数字电路符号：

| 元件 | 物理实体 | 逻辑身份 |
| :--- | :--- | :--- |
| **定针** | 相位被钉死的边界收发针（铜钲桩） | 常量 / 已知证据（Ground Term） |
| **游核** | 未锁定的起振晶格，携带离散相位槽 `φ ∈ {0..K-1}` | 逻辑变量（`fresh`） |
| **耦合导轨** | 紫晶导轨（`PulseLink`，`area ≥ 0.5` 锁相阈，札记 07 §3.2） | `==` 约束 |
| **分水桥** | 反相抑制桥（抵消窗死区，札记 08 §2.1） | `neq` 约束 |
| **检视水柱** | 固定的验真脉管（水柱高低/辉光呼吸） | 候选存活集的只读投影（§5.2） |

盘面规模锁死 **3~5 个自由核**的小尺寸；孔位完全平等——**插定针即输入，放游核即待求**，正向推演与反向溯因用同一块盘、同一套导轨（无方向性是核心玩点，见 §8 铁律 1）。

### 3.2 三态元胞与离散步进

盘内不碰连续 ODE：元胞只有三态 `静息(0) / 激发(1) / 不应期(R..1)`（Greenberg-Hastings），整数 tick 步进。GH 元胞机本身即属可激发介质——螺旋波、脉冲、不应期词汇与大山连续场全部通用，物理连续性叙事不破；盘面是大山的**离散仪器近似**，不是大山本身。

### 3.3 两条脉冲原语

- **`==`（同相牵引）**：导轨相连的两核若相位不同步，慢拍被快拍脉冲提前触发，相位差逐拍拉近，直至锁入恒定相位差稳态——**锁相 = 变量绑定**，且沿导轨自动传递闭包。
- **`neq`（同相相遇即互耗）**：两核滑入同一相位槽时，脉冲在分水桥心同相相撞、落入抵消窗**互相湮灭**；没有脉冲穿过桥维持共振，失去正反馈的游核自然滑移（`φ+1`）到下一槽位继续试探。冲突惩罚的「改道」来自失稳，无需显式规则——这就是振荡器网络中抑制性耦合（负耦合常数）的离散版，与大山心跳抵消窗同一语义来源。
- **确定性对称破缺（结算纪律）**：完全对称的两核若同相互耗后同步执行 `φ+1`，下一拍会手拉手滑进同一新槽位，形成对称死锁（两人面对面让路总撞到同一边）。离散步进规则必须内建固定微破缺：按孔位编号顺序依次结算滑移，或给不同孔位分配互质的本征滑移步长/不应期余量（差一个子拍）。全程无需随机数，保持 100% 确定性可回放；一旦相撞必然一快一慢错开槽位。**破缺参数随盘族定义进盘契约**——穷举验证的对象必须是含结算纪律的真实步进规则，验过的机器与出厂的机器才是同一台。

### 3.4 失败语义：廉价而有信息量

- 支路冲突**绝不炸毁元器件**：表现为该支路因同相互耗而辉光熄灭 / 水柱跌落；「一条支路暗下去 = 24 候选里的一个错误假说被物理否证」，排错过程本身即刑侦正反馈。
- 边界条件自相矛盾（无解）时，盘面进入**阻挫态**：指针/水柱小幅打颤、永远无法锁定。拔掉一根定针，盘面瞬间恢复。
- **试错成本严格为零**：试探失败不再对应札记 08 的过载烧毁（那是盘外大山的代价语义）；盘内试探是可逆的软消隐。

## 4. 判定健全性与盘契约（路线甲）

### 4.1 问题：伪吸引子即假否证

弛豫式求解器存在经典病灶——**伪吸引子（spurious attractors）**：有解配置可能掉入极限环而不收敛，盘面表现为阻挫；而无解与假阻挫对玩家不可区分。刑侦装置一旦会「撒谎」（玩家推理正确却被仪表骗作此路不通），信任地基即毁。因此判定健全性（soundness & completeness）必须由契约保证，不能交给动力学运气。

### 4.2 裁定：限定盘族 + 编纂期穷举验证

- 验山盘为**制式仪器**：底盘刻槽固定（如省水文队配发的三元/四元盘），只有 3~5 个孔位供插定针、放游核、拨分水阀。合法配置空间仅数百至上千种。
- 编纂期（Elixir 测试规范）**穷举该盘族全部合法配置**，逐条断言：
  1. **CSP 有解的配置 ⟹ 离散动力学在 `N_max` 步（如 60 步）内单调锁相收敛**——无伪吸引子；
  2. **无解配置 ⟹ 在 `M_max` 步内进入可检测的周期环**——离散确定性有限状态机必然入环，盘面状态哈希重复即判定入环，仪器**主动宣告阻挫**，而非让玩家对着永远打颤的指针猜测。
- 验证产物固化为 **`contracts/dial-board-v1.json`**（与 `mandate-slice-v1.json` 平级）：盘族定义 + 逐配置收敛/入环界限 + §6 违规配置的受控自激行为表。契约 schema 只描述盘族（槽道、孔位、元件、界限），**不含任何山体语义**——24 候选只是这份通用契约的一个生成来源。Scala 运行时按契约驱动表现层，**零运行时判官**；「盘面的离散物理本身就是 100% 健全的真理层」由契约测试钉死。
- 手感纪律：1980s 地质仪器的乐趣在于「摸清一台老仪器的脾气」，而非自由飞线的布线内卷；制式黑盒形态（铸铁/胶木外壳、固定槽道、铭牌批号）同时是叙事资产。

## 5. 玩法闭环与读数同源

### 5.1 标准主循环（五段式）

> **① 现场验山**（钟表/指南针测出此刻山体的漂移相位与滞后，札记 07 §5 第 2 条）
> → **② 钉针入盘**（实测相位 + Hop 1–4 卷宗证据作为定针插进盘缘）
> → **③ 弛豫指认**（同相互耗剪除矛盾支路，游核锁入唯一驻波槽，指认隐藏因果并锁死针对「此刻山体」的 `safe_tick` 相位处方）
> → **④ 合闸镇山**（拉下合闸杆，盘缘发射水晶在解出的 `safe_tick` 窗口向真实区块 `MandateRuntime` 投递 `FirePulse`，抵抗 E4/E4b 漂移或完成 `c0` 重锚）
> → **⑤ 大山阅卷**（慢速 FHN 连续场接收脉冲，演算沉滞庇护或结局跃迁）。

山的周期随慢变量漂移（`PhaseResponse` 周期动态重算），因此盘的解永远是**针对此刻之山的处方**——验山永远是第一步；推理是静态的，验收是动力学的（E4/E4b 抵抗是真实考试，不是剧场）。

### 5.2 候选灭绝读数与契约同源

通用组件只暴露**各变量的存活域**（约束传播下的 domain wipeout，与山无关的通用 CSP 信息）；物品层把它解释为 24 候选世界的存活集——检视水柱物理上对应 `Ascribe` 的关键归因维度（源头频段、阻尼完好度等）。存活候选集**直接从盘契约的存活集生成**，不写第二份逻辑——插第 1、第 2 根定针（Hop 1–2 证据）时，违反该证据的支路因同相互耗当场熄灭，玩家肉眼可见候选集从 24 缩减到 6、再到唯一亮起的驻波回路。两处语义同源，杜绝「灵异分歧」。

## 6. FORCEDENTRY 保留条款：操作规程即攻击面

限定盘族反而成全了「越界自举」的高光时刻——自由拓扑没有破解感（系统本来就允许乱连），**唯有制式仪器才有真正的 Exploit**：

- 《制式验山盘操作规程》规定：「外圈孔位仅限定针（输入观测），中心孔位放置游核（读取解），**严禁反插或跨槽短接，以免引发回波自激**」。「严禁」二字即最诱人的漏洞通告。
- 前中期玩家按规程把盘当被动推理表查 24 候选真凶；后期要逆转 `:open` 山谷结局时，依 jar 内 `.ex` 手稿（或 Hop 4 卷宗）的暗示**故意违规**——在边界孔塞进游核、或将分水桥反相卡进抵消窗死区——触发预设的**受控自激振荡（驻波自举）**，验山盘从测量表变成**自动锁相脉冲发射机**（即自适应相位补偿器，自动维持沉滞庇护 / 抵抗 E4/E4b，衔接札记 08 §2.4 自动化心跳的涌现位）。
- 两层诚实：diegetic 层面这对水文队是真实的 FORCEDENTRY（他们没料到自己的滤波算子被组合成状态机）；extra-diegetic 层面这是**被设计好的秘密机制**——违规配置同属限定盘族的有限状态集，全部经 §4.2 盘契约穷举验证，运行时按契约查表，绝无恶性 bug。游戏里的「破解」必须是设计者想到、但让玩家以为是玩家想到的。
- 叙事焊接：水工队当年仿卢基扬诺夫机修涵洞、埋测压管、架压电换能器，本只想造一台「以山测山」的线性渗流计算机；菌网滞后（`M` = 记忆元件）与铜钲抵消窗（`c0` = 非线性时序门）混入管网后，线性积分器跨过通用性阈值，自举为带记忆与自维持闭环的**地质级寄生状态机**——快脉冲改写慢介质阻抗（信号改写 plumbing 本身）即是那台机器的「自修改时刻」。**他们以为自己在接管子，其实是在流片。** jar 内 `.ex` 源码即技术员试图用逻辑语言形式化这台失控机器的遗物手稿。

## 7. 工程边界与接线现状

- **不动**：四维 RK4 方程、`mandate-slice-v1.json` 数值契约、`Regime`/`PhaseReading` 枚举名。盘内离散元胞为全新独立小实例，落于 **`inner/dial/`**（通用组件，不绑 `ChunkPos`、不 import Mandate/Minecraft，循 `MandateGrid.CellCoord` 抽象整数对先例），`inner/` 纯度不破；山只在物品绑定层（验山读数 → 定针、合闸 → `FirePulse`）出现。
- **复用**：拓扑增删走 `EventDTO` 的 `AddLink` / `RemoveLink`（札记 07 §6 已预留）；盘面状态随 `MandateSnapshot` 思路持久化；水晶薄桥的 `FirePulse` 走现有协议（发射器闭枚举纪律不破，札记 07 §1）。
- **分层纪律**：红石只碰**信号层**（水晶换能、盘面时序）；**功率层**（涵管/分水堰/节流阀改写 `LatticeEdge` 扩散/平流系数与局部 `c0`）属后续札记范畴，本札记不含。
- **真理分布**：编纂层（Elixir）生成候选空间与盘契约；盘面物理即真理层（契约保证）；本体层（大山 FHN）是验收层。Scala 运行时无判官、无隐藏逻辑。

## 8. 四条设计铁律（动工纲领）

1. **无方向性（Relational Directionlessness）是核心玩点**：孔位平等，定针即输入、游核即未知数；正向推演与反向溯因共用同一块盘、同一套导轨——方向在查询时涌现，不刻在仪器上。
2. **极简离散物理**：绝不碰连续 ODE 数值契约；盘内只有三态元胞（`0 / 1 / R..1`）与两条原语（同相牵引、同相互耗）。
3. **廉价而有信息量的失败**：支路冲突只熄辉光/跌水柱，不毁元器件；「支路暗下 = 候选被否证」；无解必在 `M_max` 内可判定地宣告阻挫（契约断言），**仪器永不撒谎**。
4. **永不暴露门**：盘面 3~5 核小尺寸；词表只用定针/游核/分水桥/对时/合闸/验山；反馈只用辉光呼吸、水柱高低、指针偏摆、铜音节拍——不出现任何数字电路符号。

## 9. 未决实验与后续排期

1. 盘族具体形制：三元/四元盘的孔位几何、相位槽数 `K`、对称破缺参数（结算次序/步长偏移，§3.3）、`N_max` / `M_max` 实测界限（最小契约原型：Elixir 穷举一个三元盘配置空间，验证收敛/入环界限——穷举必须跑含对称破缺的真实步进规则，产出 `dial-board-v1.json` 首版）；
