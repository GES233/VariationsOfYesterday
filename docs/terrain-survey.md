# 原版地形 D8 认领实验

本轮包含生成期地形采集与游戏内 D8 勘测原型：先保留原版及自定义生成器可提供的地形证据，再验证下游与局部汇水单元。阶段样本随区块保存；尚未生成聚落、写入持久化认领或接入 Mandate 平流边。

## 使用

开启作弊或具备权限等级 2，在目标山谷执行 `/voy terrain`，默认半径 4 区块；`/voy terrain 8` 扩大到半径 8 区块。命令在执行者所在维度、所在位置采样，不受当前 Mandate 固定晶格范围限制。

输出包含采样覆盖率、脚下区块的下游坐标、汇流量、终点类型，以及最大的八个局部汇水单元。坐标均为区块坐标；汇流量按贡献区块数计，包含自身。

仅读取已经加载的完整区块，不强制加载或生成。一次调用重新采样，故建筑和地形修改可以影响结果。

`/voy terrain` 同时报告生成阶段样本覆盖率、仅回退样本数、脚下地面中位高程与液深，以及两阶段高度变化柱数。D8 仍基于现场高度图，历史样本不混入同一张高程图。

`/voy terrain export [radius]` 将范围内已有附件导出到当前存档的 `voy-terrain/*.csv`，每份文件独立命名。每行是一根柱，含区块／方块坐标、阶段、生成器类名、世界高度范围、地表 Y、地面 Y、液深。缺失阶段不伪造数据，地面 Y 为 `bottom_y - 1` 表示未发现地面。导出不请求区块加载。

## 生成采集与兼容边界

- 可选 Mixin 在 `ChunkGenerating.buildSurface` 返回的 future 完成后采集 `surface_stage`，链接在后续阶段之前；不限定 `NoiseChunkGenerator`。1.21.2 中此时还未完成后续雕刻与特征生成，不能把该阶段称为完整、未经结构影响的天然地形。
- Fabric `ServerChunkEvents.CHUNK_LOAD` 在首次完整区块加载时记录 `first_full_observation`。它可能来自新生成区块，也可能是已经被改造的旧存档；绝不补造早期样本，也不宣称这是生成完成瞬间的快照。
- 两个不可变附件通过 Fabric Data Attachment API 保存于各自区块 NBT，生成中区块转为完整区块时由 Fabric 转交。没有全世界常驻缓存、跨区块采集或生成线程上的 Mandate 修改。
- 每份样本保留 16×16 的逐柱数据。依已有 `WORLD_SURFACE_WG`／`WORLD_SURFACE` 高度图定位柱顶，再向下识别地面和非空流体；不主动补建高度图。缺少高度图或采集失败时保留缺失状态、限次记录日志，不使生成 future 因采样失败而异常。
- `terrain_ignored` 方块标签默认跳过 `#minecraft:leaves` 与 `#minecraft:logs`；`terrain_ground` 标签可补充自定义地面，默认空。两者位于 `data/variations-of-yesterday/tags/block/`，可由数据包扩展或替换，忽略规则优先。普通地面沿用原版 OCEAN_FLOOR 的 `blocksMovement` 判据。
- 液体按非空 FluidState 识别，包含模组流体及熔岩；液深不是水种类判定，含水固体作为地面。屋顶、浮岛仍可能是最高有效地面，二维柱采样不解决地下多层空间。
- 早期注入 `require=0`，修改或绕过该生成阶段的模组可以仅留下完整观测。它不保证与任意改写同一方法的 Mixin 兼容；需要在目标模组组合中实测。
- 原始样本只写一次，重载不覆盖。更换生成器、采样标签或版本后，已有样本不自动重算；跨阶段差异可能包含采样规则变化，不能直接归因于玩家。V1 保存生成器类名和格式版本，尚未保存完整数据包指纹。
- “认领”只表示自然区域分析，与领地权限无关；本轮不放置／破坏方块，也不向经济或灾害系统施加效果。

在 `config/variations-of-yesterday.json` 中添加以下字段（旧配置缺少该段时采用这些默认值，修改后重启）：

```json
"terrain": {
  "enabled": true,
  "earlyCapture": true,
  "dimensions": ["minecraft:overworld"]
}
```

`enabled: false` 禁用自动采集；`earlyCapture: false` 只保留首次完整观测；其他维度须显式加入。禁用不删除已有样本，现场勘测与导出仍可使用。

## 算法与边界

- 每区块对 256 根柱的 `MOTION_BLOCKING_NO_LEAVES` 高度取中位数，降低孤立柱的影响；水面、树干和建筑仍可能影响结果。这是粗粒度地表，不是地下水或真实地质模型。
- 八邻域按落差除以距离选最陡下降方向，对角距离为 √2；等坡度按北、东北、东、东南、南、西南、西、西北顺序选择。
- 任一邻居未采样，该格即为开放扫描边界，不猜测出流方向。上游认领沿严格下降链追到终点，因此不存在环。
- 完整邻域中无下坡且存在等高邻居，标为待解平地；全部邻居更高则标为局部洼地。本轮不填洼、不强制排水平地。
- 相同终点形成一个临时汇水单元。开放边界和平地不是完整流域；扫描外还可能有上游来水，汇流量只是本次范围内的下界。

## 游戏内验收建议

分别在山坡、谷底、平原和海岸执行命令，再换两个种子重复。检查下游方向是否符合肉眼地势，扩大扫描后边界是否合理外移，以及区块中位数是否抹掉了窄沟。若窄沟识别失败，应先比较更细采样尺度，再把结果接入地脉或分配叙事节点。

自动测试覆盖距离归一化、汇流守恒、平地与洼地区分、缺失邻居和空输入；真实种子的效果需要游戏内验证。

生成采集验收：先在旧区块查看“仅回退”，再到未生成区域检查早期样本出现；导出后退出重进，确认原坐标样本保持一致。再分别测试自定义地形、结构装饰及自定义维度组合，核对缺失／差异来源；目前未宣称这些第三方模组组合已经通过验证。
