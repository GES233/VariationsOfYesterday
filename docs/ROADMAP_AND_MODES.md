# 发版节奏与世界模式规划（Roadmap & World Modes）

> **状态**：方向已定（2026-11-16），在排期层面冻结口径，后续按批推进。

## 1. 发版策略：先引流，后留存

1. **0.1 引流期 — 聚焦「剧情模式（旧日谷地）」**
   - 目标：开局 3 分钟建立异常压迫感，30–60 分钟走完「敲钟起搏 → 热点核逼近 → 黄水与失能 → 泄压再接种」完整戏剧弧。
   - 暂不做建档模式切换 UI 与一般模式，优先跑通 0.1 最小可玩闭环。
2. **后续留存期 — 主推「一般模式（生态漫游）」**
   - 目标：服务种田养老、自动化与整合包玩家长期留存；建档默认仍为「旧日谷地」，提供按钮切换至「生态漫游」。

## 2. 0.1 近期收尾清单（按优先级）

1. **合回架构清理分支**：验证 `refactor/clean-arch` 敲钟三态（`叩钟 / 叩钟过密 / 叩钟无应`）游戏内手感后合入主分支。
2. **补齐表现与开局引导**：
   - 补齐 3 个 `18×18` 状态图标（`stagnation`、`stagnation_spike`、`pulse_saturation`）；
   - 接入开局前 3 分钟钩子与引导，让玩家不看文档也能理解「敲钟养心跳 + 护菌」。
3. **落地 WO-2 泄压设施（石灰石沟 + 人工湿地）**：
   - 实现 `CalmingBus` 汇总投递 `SetCalming`、铁锈装甲化与清淤维护，交出热点核救赎手段（$c \gtrsim 2u$）。

## 3. 未来「建档二选一」规则包（Consolidated）

在 `CreateWorldScreen` 提供独立循环按钮（不做零碎开关，也不占用 `WorldPreset` 以免冲突），建档时一次性写入存档头（`MandatePersistence`），中途不可切换：

| 对比维度 | **旧日谷地（剧情模式 / 0.1 默认）** | **生态漫游（一般模式 / 后续 Feature）** | 工程接缝 |
| :--- | :--- | :--- | :--- |
| **初始场与空间范围** | 预设谷地热点核 + 8×8 余脉环 | 平坦无危机起点（`s=0, M=1`），随玩家活动动态激活区块 | `MandateField` 接口（`mandate/MandateField.scala`） |
| **平静静息（`Calm + Slow`）是否沉滞** | **算**（「镇死 = 沉滞」，倒逼敲钟养心跳） | **不算**（平静存活即 `Maintained`；仅挖坏/过驱动/酸蚀触发异常） | `MandatePhenomena.classifyEconomy` 按 `WorldMode` 分流 |
| **敲钟与设施定位** | 开局生存刚需与救灾生命线 | 开大矿/机器前的缓冲护符与矿难急救器 | 方程、Actor、`BellRitual` 与美术文案**零改动复用** |
| **叙事结构与卷宗** | 投放聚落遗址、钻探台与五跳卷宗 | 不投放强主线危机遗址，纯生态游玩 | 仅影响 worldgen 投放条件 |

## 4. 明确延后项（0.1 不碰）

- 三通道原子事实流重写、S2C 协议重做与 `SchemaVersion = 4` 断档；
- `PulseOutcome` 事后回声（需「校拍/静息/失锚」文案回流时再加）；
- D8 地势平流、Node 动态休眠调度与外迁 Elixir 卷宗接入。
