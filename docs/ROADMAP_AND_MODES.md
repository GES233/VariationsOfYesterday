# 发版节奏与世界模式规划（Roadmap & World Modes）

> **状态**：方向已定（2026-11-16）。本规划只在构想与排期层面冻结口径；具体实施在后续版本按批推进。

## 1. 发版策略：先引流，后留存

1. **0.1 早期版本（引流期）——聚焦「剧情模式（旧日谷地）」**
   - 目标：让首批玩家与视频创作者在开局 3 分钟感受到异常与压迫感，在 30–60 分钟内走完「敲钟起搏 → 热点核逼近 → 黄水与失能 → 泄压再接种」的完整戏剧弧。
   - 此阶段暂不分散精力做建档模式切换 UI，也不提前实现一般模式；保持代码轻巧，优先补完 0.1 最小可玩闭环。
2. **后续大版本（留存期）——「一般模式（生态漫游）」作为主推 Feature**
   - 目标：吸引养老种田、技术自动化与整合包玩家长期留存；默认建档仍可保持「旧日谷地」主推体验，建档界面提供切换至「生态漫游」。

## 2. 0.1 近期收尾清单（按优先级）

1. **合并当前架构清理分支**：确认 `refactor/clean-arch` 游戏内敲钟三态（`叩钟 / 叩钟过密 / 叩钟无应`）手感后合回主分支。
2. **补齐表现与开局引导**：
   - 补齐 3 个 `18×18` 状态效果图标（`stagnation`、`stagnation_spike`、`pulse_saturation`）；
   - 加入轻量开局前 3 分钟钩子与引导，让玩家不看外部文档即可理解「敲钟养心跳 + 护菌」。
3. **落地 WO-2 泄压设施（石灰石沟 + 人工湿地）**：
   - 实现 `CalmingBus` 汇总投递 `SetCalming`、铁锈装甲化与清淤维护，把热点核救赎（$c \gtrsim 2u$）真正交到玩家手里。

## 3. 未来「建档二选一」设计备忘（Consolidated 规则包）

不把模式拆成零碎开关，也不做成 `WorldPreset`（避免与原版/第三方地形模组冲突）；而是在 `CreateWorldScreen` 加一个独立循环按钮，建档时一次性固化写进存档头（`MandatePersistence`），中途不可切换：

| 对比维度 | **旧日谷地（剧情模式 / 0.1 默认）** | **生态漫游（一般模式 / 后续 Feature）** | 工程接缝 |
| :--- | :--- | :--- | :--- |
| **初始场与空间范围** | 预设谷地开局携带热点核 + 8×8 余脉环 | 无预设危机（`s=0, M=1` 平坦起点），随玩家活动动态激活区块 | 已预留 `MandateField` 接口（`mandate/MandateField.scala`） |
| **平静且静息（`Calm + Slow`）是否沉滞** | **算**（公理：「镇死 = 沉滞」，逼玩家敲钟养心跳） | **不算**（沙盒直觉：平静存活即 `Maintained`；只有挖坏/过驱动/酸蚀才触发黄水、沉滞与尖峰） | `MandatePhenomena.classifyEconomy` 按存档 `WorldMode` 分流 |
| **敲钟与设施定位** | 开局生存刚需与救灾生命线 | 开大矿/机器前的缓冲护符与矿难急救器 | 方程、Actor、`BellRitual` 与美术文案**零改动复用** |
| **叙事结构与卷宗** | 投放聚落遗址、钻探台与五跳卷宗（未来接回） | 不投放强主线危机遗址，纯生态游玩 | 仅影响 worldgen 投放条件 |

## 4. 明确延后项（0.1 不碰）

- 三通道原子事实流全量重写、S2C 协议重做与 `SchemaVersion = 4` 断档；
- `PulseOutcome` 事后回声（若需要「校拍/静息/失锚」文案回流再加）；
- D8 地势平流、Node 动态休眠调度与外迁 Elixir 卷宗接入。
