# 创作圣经（Creative Bible — 策划 / 美工 / 剧情唯一参考）

> **给合作者的说明**：无需理解微分方程、Actor 或 `docs/archive/` 历史讨论。写剧情、定美术或加物品前，只看本文档即可。

## 1. 一句话定位

《旧日变奏曲》（*Variations of Yesterday*）是一款 **1980s 架空山区水文地质工程 × 民俗恐怖氛围 × 可恢复的活体生态模拟** Minecraft 模组（「三重梦境」三部曲第一幕）。

核心冲突：**山是活着的。人越想用暴力和秩序把它强行镇死，地底的发光菌网就越先坏死、山谷就越沉滞；唯有顺着它的脉搏起搏、泄压、培菌，这片「地底星空」才会重新亮起来。**

## 2. 三条创作铁律（红线）

1. **完全虚构、去具体地域**：
   - 不出现任何真实省份、真实民族、真实方言考据词（早期「滇西南巫祭」设想已废除）。
   - 通用意象：**深山、冷雨、老寨、古钟（铜钲）、分水石堰、1980s 国营工矿/林场驻地、红砖房、钻探台与手写台账**。
2. **真实物种名不进玩家视野**：
   - 内部灵感虽来自真菌/块根共生与酸性矿山排水（AMD），但**玩家可见文本一律使用纯虚构词**，严禁出现「天麻」「蜜环菌」等真实学名。
3. **恐怖只在氛围与钩子，机制层永远留温柔余地**：
   - 不做脚本跳脸、不逼玩家站桩读公文。恐怖来自行为引发的生态反噬（水变黄浊、夜光骤灭、寨子死气沉沉）。
   - 机制只有「失能」没有永久「绝死」：哪怕全谷枯绝，停手降酸后再接种菌种，菌光与生计都能救回来。

## 3. 玩家侧因果与物候语言（世界即仪表盘）

| 世界状态 | 玩家能看到/听到的物候 | 机制发生的事（通俗版） | 玩家的应对 |
| :--- | :--- | :--- | :--- |
| **平静且菌网完好（夜间有安抚源）** | 地面偶现微弱夜光（`GLOW`）；**菌塘**正常生长；寨里交易与农耕正常 | 地脉平静、$c_0$ 安抚源在线、菌网完好 | 采集**鲜伏根**、用**段木**伴栽扩产 |
| **受压 / 临界前兆** | 水边浮现浅至中度**黄水**粒子；若有安抚源，空气飘起前兆孢子；敲钟可起搏 | 采矿/爆破推高土地应力，接近自然起振带 | 放慢采掘，用古钟规律叩击（**30–60 s 一拍**，忌 8 s 内连敲） |
| **心跳过快 / 失律（急性）** | 玩家挖掘极慢（`沉滞·尖峰`）、伴随缓慢与灰烬；交易暴涨、繁育停滞 | 敲钟过密或地脉进入紊乱高频区间 | 停手退后，吃**煨伏根**缓解震麻与迟滞，等待节律回稳 |
| **心跳断绝 / 镇死（沉滞）** | 村民挂**沉滞**、交易加价、农耕繁育受抑（**玩家自身无负面效果**） | 土地久无节律，或过度安抚把脉搏镇死了 | **「镇死 = 沉滞」**：用古钟重新起搏唤醒脉搏 |
| **菌网枯绝 / 深度失能（死寂）** | 地面剩白灰、菌光熄灭、**菌塘**黑腐枯萎、**叩钟无应**（蜡烛闷熄声 + 死灰） | 长期高应力酸蚀（$s \ge 0.60$）耗尽菌网，或恢复偏移垮塌 | 先停采泄压退酸，再持菌种或潜行持**荧丝菌材**对土**再接种**，重铺菌塘 |

## 4. 标准化词表与禁写清单（写手必查）

### 4.1 玩家侧标准用词
- **核心术语**：`地脉`、`菌网`（完好 / 受损 / 枯绝）、`黄水`、`沉滞`、`沉滞·尖峰`、`脉冲过载`
- **生态与农事**：`荧丝`（发光菌丝）、`菌塘`、`荧丝菌材`（段木伴栽）、`鲜伏根`、`煨伏根`
- **叩钟反馈**：`叩钟`（成功起搏 + 锚定安抚源）、`叩钟过密`（8 s 内连敲反震）、`叩钟无应`（死寂地脉无回音）
- **观测读数**：手持原版**钟**或**指南针**右键方块，动作栏显示当前区块定性状态与 `20` 格参考刻度（纯观测，非敲钟门槛）。

### 4.2 严禁再写的旧设定（已废除）
- ❌ **「必须在相位对齐时敲钟 / 错过相位窗会被吞」**：钟已是**起搏器**（随时可敲，只判是否死地、是否 8 s 内连敲）。
- ❌ **「40 秒脉动保鲜窗 / 窗外就沉滞」**：庇护来自**连续心跳节律**，非单次敲钟 40 s 倒计时。
- ❌ **「连敲会让后续脉冲越来越难起效」**：无耐受衰减；连敲只触发即刻反震（`pulse_saturation`）和 8 s 守卫拒收。
- ❌ **真实物种、真实省份/少数民族名**：不写天麻、蜜环菌、云南、滇西南等词。

## 6. 核、残核与玩家的存在（2026-11-17 确定，尚未实装）

工程现状见 `CURRENT_ARCHITECTURE.md` §4.1，创作与玩法边界遵循以下四条：

1. **核与多处残核**：「核」是菌网在局部形成的密集高阶组织（残影仅重复前人工作残留，非菌网主动规划）。世界可有多枚核，**仅一处承载开局引入历史**；其余为残核，可随生态恢复被激活，但不召唤玩家、不重播开局。
2. **玩家独立存在**：核的尝试曾引入玩家，但引入完成后玩家即符合世界规则独立存在——**核不是必须守护的生命维持装置**。菌网枯绝或核被毁均不删档、不锁死重生；晚加入者在原核已毁时仍须通过替代载体获得个人引导。
3. **允许毁核，历史保留**：核可被破坏（开局塌棚默认留下残核，此后亦可拆除），拆除、替换或激活其他核均不重置世界开局与个人引导记录：

| 情形 | 约定后果 |
| :--- | :--- |
| 菌网失活，核结构尚在 | 结构存在不等于活跃；恢复条件与反馈待定义 |
| 核被敲掉 / 移除 | 原址失去核功能与演出反馈，不可对空气继续滋养 |
| 菌网枯绝且核被移除 | 玩家正常存活、登录与重生；开局与个人引导历史照常保留 |
| 毁核后恢复当地菌网 | 生态恢复不自动复原物理核，复杂结构重建另行处理 |

4. **开局表现边界**：剧情模式沿「出生点 → 最近山谷」引导且小棚会塌（一般模式不塌，水系上下游不作强导航依赖）；`Nourished` 仅代表开局流程终结（不再重播），不代表物理核不可破坏。
