# 创作圣经（Creative Bible — 策划 / 美工 / 剧情唯一参考）

> **给合作者的说明**：你不需要看懂微分方程、Actor 或 `docs/archive/` 里的历史技术讨论。写剧情、定美术或加物品前，只看这一份文档即可。

## 1. 一句话定位

《旧日变奏曲》（*Variations of Yesterday*）是一款 **1980s 架空山区水文地质工程 × 民俗恐怖氛围 × 可恢复的活体生态模拟** Minecraft 模组（也是「三重梦境」主题三部曲的第一幕）。

核心冲突：**山是活着的。人越想用暴力和秩序把它强行镇死，地底的发光菌网就越先坏死、山谷就越沉滞；唯有顺着它的脉搏起搏、泄压、培菌，这片「地底星空」才会重新亮起来。**

## 2. 三条创作铁律（红线）

1. **完全虚构、去具体地域**：
   - 不出现任何真实省份、真实民族、真实方言考据词（早期的「滇西南少数民族巫祭」设想已废除）。
   - 通用背景意象：**深山、冷雨、老寨、古钟（铜钲）、分水石堰、1980s 国营工矿/林场驻地、红砖房、钻探台与手写台账**。
2. **真实物种名不进玩家视野**：
   - 内部灵感虽来自真实真菌/块根共生与酸性矿山排水（AMD），但**玩家可见的任何名称、对话、物品描述都只用纯虚构词**，严禁写「天麻」「蜜环菌」等真实学名。
3. **恐怖只在氛围与钩子，机制层永远留温柔余地**：
   - 不做脚本跳脸、不做强制站桩读公文。恐怖来自玩家行为引发的生态反噬（水变黄浊、夜光骤灭、寨子死气沉沉）。
   - 机制上只有「失能」没有永久「绝死」：哪怕整块山谷枯绝，停手降酸后再接种菌种，菌光与生计都能救回来。

## 3. 玩家侧因果与物候语言（世界即仪表盘）

| 世界状态 | 玩家能看到/听到的物候 | 机制发生的事（通俗版） | 玩家的应对 |
| :--- | :--- | :--- | :--- |
| **平静且菌网完好（夜间有安抚源）** | 地面偶现微弱夜光（`GLOW`）；**菌塘**正常生长；寨里交易与农耕正常 | 地脉平静、$c_0$ 安抚源在线、菌网完好 | 采集**鲜伏根**、用**段木**伴栽扩产 |
| **受压 / 临界前兆** | 水边开始出现浅至中度**黄水**粒子；若有安抚源，空气中出现前兆菌丝孢子；敲钟可起搏 | 采矿/爆破推高土地应力，接近自然起振带 | 放慢采掘，用古钟规律叩击（**30–60 s 一拍**，切忌 8 s 内连敲） |
| **心跳过快 / 失律（急性）** | 玩家自身感到挖掘极慢（`沉滞·尖峰`）、伴随缓慢与灰烬；交易暴涨、繁育停滞 | 敲钟过密或地脉进入紊乱高频率区间 | 停手退后，吃**煨伏根**缓解身体震麻与迟滞，等待节律回稳 |
| **心跳断绝 / 镇死（沉滞）** | 村民挂上**沉滞**状态、交易加价、作物生长与繁育受抑（**玩家身体不吃负面效果**） | 土地太久没有节律，或过度安抚把脉搏镇死了 | **「镇死 = 沉滞」**：用古钟重新起搏唤醒脉搏 |
| **菌网枯绝 / 深度失能（死寂）** | 地面只剩白灰、菌光彻底熄灭、**菌塘**黑腐枯萎、**叩钟无应**（蜡烛闷熄声 + 死灰） | 长期高应力酸蚀（$s \ge 0.60$）耗尽菌网，或恢复偏移彻底垮塌 | 必须先停采泄压让酸毒退去，再持菌种或潜行持**荧丝菌材**对土壤**再接种**，最后重铺菌塘 |

## 4. 标准化词表与禁写清单（写手必查）

### 4.1 玩家侧标准用词
- **核心术语**：`地脉`、`菌网`（完好 / 受损 / 枯绝）、`黄水`、`沉滞`、`沉滞·尖峰`、`脉冲过载`
- **生态与农事**：`荧丝`（发光菌丝）、`菌塘`、`荧丝菌材`（段木伴栽）、`鲜伏根`、`煨伏根`
- **叩钟反馈**：`叩钟`（成功起搏 + 锚定安抚源）、`叩钟过密`（8 s 内连敲反震）、`叩钟无应`（死寂地脉无回音）
- **其他工具读数**：手持原版**钟**或**指南针**右键方块，可在动作栏读取当前区块的定性状态与 `20` 格参考刻度（纯观测，不作为敲钟门槛）。

### 4.2 严禁再写的旧设定（已废除）
- ❌ **「必须在相位对齐时敲钟 / 错过相位窗会被吞」**：敲钟早已改为**起搏器**（随时可敲，只判是否死地、是否 8 s 内连敲）。
- ❌ **「40 秒脉动保鲜窗 / 窗外就沉滞」**：庇护来自**连续心跳节律**，不再是单次敲钟开 40 s 倒计时窗。
- ❌ **「连敲会让后续脉冲越来越难起效」**：已无脉冲耐受度衰减；过密敲击只会触发即刻反震（`pulse_saturation`）和 8 s 守卫拒收。
- ❌ **真实物种、真实省份/少数民族名**：不写天麻、蜜环菌、云南、滇西南等词。

## 6. 核、残核与玩家的存在（2026-11-17 确定）

本节为创作与玩法边界，实体核、结构生成及破坏后的交互尚未实装。工程现状与待调整项见 `CURRENT_ARCHITECTURE.md` §4。

### 6.1 核的身份与多核结构

- **核是菌网在局部形成的密集、高度组织化结构**，承载更复杂的遗留结构与反应。“维度更高”作为创作理解保留，不据此新增游戏维度、模拟变量或智能规划系统。
- 核的结构仍在与核正在活动是两回事。世界可存在多处此类结构；仅保留一处承载开局引入及相关玩家交互的历史，其余视为残核，可随环境恢复而被激活。
- “曾成功引入玩家”是一段历史，不必另设一种特殊核。其他残核激活不自动召唤玩家，也不自动重播开局；各自功能与激活条件待定。
- 残影实体重复过去某个人的工作残留，不表现为菌网主动规划解决方案。

### 6.2 玩家引入完成后独立存在

菌网与核的失败尝试曾留下实体，某次成功引入了玩家。玩家虽由这一过程来到世界，却因符合游戏的运行机制而成为游戏的一部分；引入完成后，不再依赖核或菌网持续维持。

- 核不是玩家必须永久守护的生命装置。菌网枯绝、核被破坏均不删除角色、不禁止重生、不锁死存档。
- 开局引入解释这个世界为何向玩家开放；后续加入、登录与死亡重生不要求物理核再次完成召唤。生存与重生沿用游戏机制。
- 晚加入者仍须能得到必要的个人引导。若原核已不存在，不得凭空演出“核仍在回应”；替代引导的载体尚待设计。

### 6.3 允许毁核，历史保留

| 情形 | 约定后果 |
| :--- | :--- |
| 菌网失活，核的结构尚在 | 结构存在不保证活动；可恢复条件与反馈尚待定义 |
| 核被敲掉／移除 | 原址失去该核的功能与反馈，不能对不存在的核继续滋养 |
| 菌网枯绝且核被移除 | 玩家仍存在、可继续游玩和加入；开局及个人引导历史仍保存 |
| 毁核后恢复当地菌网 | 不自动复原核；生态恢复与复杂结构重建分开处理 |

核可被破坏；掉落物、能否搬运与重建方式尚未决定。开局棚子消散时默认保留残核，不代表残核此后不可拆除。历史记录也不能因拆除、放置或激活另一枚核而重置。

### 6.4 开局表现边界

- 剧情模式沿“出生点 → 最近的山谷”引导，小棚会塌；后续一般模式的小棚不塌。水的上下游不承担重要导航依赖。
- 不同山谷可以有不同故事；多处残核不意味着每处都承担玩家出生机制。
- 开局状态中的 `Nourished` 终态表示完成滋养后不再重播开局，不表示物理核永久有能量、不可破坏或玩家依赖它生存。
- 棚子的原始建造者、用途与确切陈设仍待确定；“人类工作棚后来被菌网利用”目前只是建议。
