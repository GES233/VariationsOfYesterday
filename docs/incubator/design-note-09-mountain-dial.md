## 0. 一句话

水文队背进深山的「验山盘」是一台**手摇式菌晶赛博格（有限域约束弛豫仪）**：以通用手摇格子步进盒为骨、活体菌丝（慢记忆）与压电紫晶（快闪光）为内胆；玩家把实测与卷宗钉成定针、把未知数放成菌苞游核，手摇曲柄激发压电闪光，盘面以「同相滋养菌丝搭桥（`==`）」与「同相电弧烧缩菌丝（`neq`）」两条离散原语把编纂期钉死的解**弛豫呈现**出来——**盘面负责把推理跑给人看，盘契约负责推理不撒谎，大山负责阅卷**。

## 1. 定位：四层栈中的「仪器层」

诚实命名先行：盘面**不是通用 Kanren 机**——无递归、无无穷域、无答案流，跑不了 `appendo`；它是**有限域约束满足（CSP）的物理弛豫盘**，恰好够承载双向关系反演与 24 候选溯因（札记 02 §3）。四层各归各位，互不冒充：

| 层级 | 载体 | 数学本质 | 1980s 叙事包装 |
| :--- | :--- | :--- | :--- |
| **1. 编纂层** | Elixir `Voy.Kanren`（`tools/voy_world`） | 完整关系编程：递归、合一、`neq/2`、`Ascribe.abduceo/4` 生成 24 候选空间与五跳证据图 | jar 内 `.ex` 源码 = 水工队技术员留下的「推理机形式化手稿」（ARG 拆包彩蛋，见 §6） |
| **2. 仪器层（本札记）** | Scala 离散 GH 元胞机 + 游离晶核（盘内独立小实例） | 有限域 CSP / 耦合振荡器弛豫：锁相即 `==`，同相互耗即 `neq` | 「卢基扬诺夫式外壳 × 菌晶赛博格内胆」的手摇验山盘：把三方残缺卷宗（Hop 1–4）插进盘缘、手摇打闪观哪条菌丝支路驻波不灭来反演真凶与对时刻度 |
| **3. 换能薄桥层** | 谐振水晶（读）+ 发射水晶（写） | A/D 与 D/A：区块连续相位/σ/M ↔ 离散脉冲/红石 0–15 档，复用 `EventDTO` | 埋入地脉露头的压电收发探针与铜钲桩 |
| **4. 本体层** | Scala `MandateGrid` + `PulseCoupling`（区块大网） | 四维连续 FHN + 慢变量滞后 + Arnold 舌锁相 + 心跳抵消窗（札记 07/08） | 大山与活体菌网本身：连续、缓慢、**真实代价唯一发生地** |

### 1.1 仪器层内部：手摇通用组件 + 菌晶赛博格组装

仪器层按「通用手摇弛豫机芯 + 模组生物矿物改装」拆分，**通用组件本身与大山无任何关联**：

- **通用组件（`inner/dial/`，纯 Scala，不 import Mandate/Minecraft）**：手摇式格子步进机芯。包含盘族定义（槽道几何、孔位、相位槽数 `K`）、定针/游核/导轨/分水桥元件、手摇驱动的 GH 三态步进呈现器、盘契约（`dial-board-v1.json`）查表运行器与存活域投影。**真理在契约查表，GH 步进只负责把过程摇出来给人看，逐拍与契约轨迹对表**（§4.2）。它是一台通用的**无方向有限域 Kanren/CSP 配平器**，只认识「变量、域、约束、解」——玩家在格子里嵌好组件并手摇曲柄供能打闪，即可在日常生存中跑**双向工序/配方反演**（锁原料与成品反推缺料火候）或**多路机关互斥配平**，完全独立于山体主线。
- **模组物品（制式验山盘 = 通用手摇机芯 + 蘑菇菌丝 + 压电紫晶）**：水工队发现纯机械齿轮与铜片算不动山体滞后，遂就地取材，在苏联式手摇铁盒的格子槽道内接种**活体夜光菌丝（慢变量记忆/导电搭桥）**、嵌装**天然紫晶簇（快变量压电震动打闪）**，组装成半机械、半生物的「土法山体赛博格」。定针读数来自验山（钟表/指南针）与 Hop 1–4 卷宗、盘契约由 24 候选空间在编纂期生成、合闸经发射水晶向 `MandateRuntime` 投 `FirePulse`。山的关联全部住在这一层。

这不是投机性泛化：穷举契约验证的对象本来就是**通用机器**（与山无关，才有封闭可穷举的状态空间）；第二个消费场景是否存在留给后续，本札记不为假想物品预留 API。

## 2. 史料锚点与灵感谱系

- **卢基扬诺夫水力积分器（1936，苏联）**：以连通管水头求解偏微分方程，最初即用于土工/水文地质问题（坝体渗流、冻土裂隙）——「编程 = 接管子，运行 = 开水阀，读数 = 看水位」，与 1980s 山区水文地质工程设定严丝合缝。
- **MONIAC（1949，Phillips）**：水力模拟国民经济的同类机器，佐证「模拟计算机 = 组织元器件 + 施加外部动力」的两步工作流。
- **FORCEDENTRY（CVE-2021-30860）**：在非可编程介质（JBIG2 解码器）中以受限原语（位图 AND/OR/XOR/XNOR）自举出通用计算机。可迁移的不是漏洞本身，而是其结构：**宿主免费求值、原语组合封闭、无控制流全展开、计算价值由写回点定义**。验山盘沿用同一骨架：玩家排布盘面（组织元器件）→ 敲钟/链路激励（施加动力）→ 引擎弛豫求值（宿主免费计算）→ 合闸写回真实区块（写回点）。

## 3. 盘面物理：手摇打闪、两条原语与零损耗试错

### 3.1 元件词表（永不暴露门）

盘面词表全部是仪器/生物矿物词，绝不出现数字电路符号：

| 元件 | 物理实体（菌晶赛博格具象） | 逻辑身份 |
| :--- | :--- | :--- |
| **手摇曲柄** | 盘侧棘轮摇把（点按单步 / 长按连摇，机械力挤压全场紫晶打闪） | 离散步进时钟（`step()` 驱动源） |
| **定针** | 相位被钉死的死晶定音针 / 铜钲桩（按固定切面拍数打闪） | 常量 / 已知证据（Ground Term） |
| **游核** | **菌苞游核**：被活菌丝包裹托举的游离紫晶，携带离散相位槽 `φ ∈ {0..K-1}` | 逻辑变量（`fresh`） |
| **耦合导轨** | **同相菌槽**：镶有紫晶导轨的菌丝营养槽（`PulseLink`，`area ≥ 0.5` 锁相阈，札记 07 §3.2） | `==` 约束（同拍闪光滋养菌丝蔓延搭桥） |
| **分水桥** | **错相电弧桥**：反相抑制桥 / 放电隙（抵消窗死区，札记 08 §2.1） | `neq` 约束（同拍闪光撞出电弧烧缩菌丝） |
| **检视水柱** | 固定的验真脉管（指示菌液水柱高低 / 辉光呼吸） | 候选存活集的只读投影（§5.2） |

盘面规模锁死 **3~5 个自由核**的小尺寸；孔位完全平等——**插定针即输入，放菌苞游核即待求**，正向推演与反向溯因用同一块盘、同一套槽道（无方向性是核心玩点，见 §8 铁律 1）。

### 3.2 手摇步进与三态元胞

盘内不碰连续 ODE：元胞只有三态 `静息(0) / 激发(1) / 不应期(R..1)`（Greenberg-Hastings），由**玩家手摇曲柄**（或合闸后的自激回路）按整数拍驱动步进——点按曲柄可单步检视每一次压电闪光与菌丝伸缩，长按曲柄则连续快速摇动直至棘轮咬合锁定。GH 元胞机本身即属可激发介质——螺旋波、脉冲、不应期词汇与大山连续场全部通用，物理连续性叙事不破；盘面是大山的**离散赛博格近似**，不是大山本身。

### 3.3 两条脉冲原语

- **`==`（同相牵引 / 菌丝搭桥）**：菌槽相连的两核若相位不同步，慢拍被快拍的压电闪光提前触发，相位差逐拍拉近，直至同拍共振、温和生物电滋养槽内**菌丝长满搭桥并亮起稳态荧光**——**锁相搭桥 = 变量绑定**，且沿导轨自动传递闭包。
- **`neq`（同相相遇即互耗 / 电弧缩菌）**：两核滑入同一相位槽时，两束压电闪光在分水桥心迎头相撞、落入抵消窗**炸出刺眼电弧互相湮灭**，将桥侧菌丝电得枯萎缩回；菌丝一缩、托举松开，结算纪律随即**显式拨槽**——相撞两核中孔位编号靠后者（结算序负方）在下一拍被棘轮联动拨进下一槽位（`φ+1 mod K`）继续试探，编号靠前者留槽不动。拨槽是写死的步进规则，不依赖「怕疼失稳」之类的涌现；语义上它对应振荡器网络中抑制性耦合（负耦合常数）的离散版，与大山心跳抵消窗同一语义来源。
- **确定性对称破缺（结算纪律）**：完全对称的两核若同相互耗后同步拨槽，下一拍会手拉手滑进同一新槽位，形成对称死锁（两人面对面让路总撞到同一边）。离散步进规则必须内建固定微破缺：**按孔位编号顺序结算——同拍相撞时编号靠后者拨槽、靠前者留槽**。元胞按整数拍步进，不存在可资利用的「子拍」相位偏移，破缺只能来自结算次序。全程无需随机数，保持 100% 确定性可回放；一旦相撞必然一留一拨错开槽位。**破缺参数随盘族定义进盘契约**——穷举验证的对象必须是含结算纪律的真实步进规则，验过的机器与出厂的机器才是同一台。

> 注意：本节描述的是 GH 呈现层的**目标行为**。这套规则能否作为自主弛豫动力学收敛到解，属 §9.1 前置原型门槛（证伪即退回机械枚举，见 §4.2）；运行时盘面表现一律以契约轨迹为准，GH 步进与之逐拍对表。

### 3.4 失败语义：廉价而有信息量

- 支路冲突**绝不炸毁元器件**：表现为该支路因同相电弧互耗而**菌丝缩回 / 辉光熄灭 / 水柱跌落**；「一条菌丝支路暗下去 = 24 候选里的一个错误假说被物理否证」，排错过程本身即刑侦正反馈。
- 边界条件自相矛盾（无解）时，盘面进入**阻挫态**：怎么摇都会挨电，菌丝全盘缩团暗灭、指针/水柱小幅打颤、手摇曲柄打滑空转。拔掉一根定针，菌丝瞬间舒展恢复。
- **试错成本严格为零**：试探失败不再对应札记 08 的过载烧毁（那是盘外大山的代价语义）；盘内试探是可逆的活菌软消隐。

## 4. 判定健全性与盘契约（路线甲）

### 4.1 问题：伪吸引子即假否证

弛豫式求解器存在经典病灶——**伪吸引子（spurious attractors）**：有解配置可能掉入极限环而不收敛，盘面表现为阻挫；而无解与假阻挫对玩家不可区分。刑侦装置一旦会「撒谎」（玩家推理正确却被仪表骗作此路不通），信任地基即毁。因此判定健全性（soundness & completeness）必须由契约保证，不能交给动力学运气。

### 4.2 裁定：限定盘族 + 编纂期穷举验证（契约 = 真理层）

- 验山盘为**制式仪器**：底盘刻槽固定（如省水文队配发的三元/四元盘），只有 3~5 个孔位供插定针、放游核、拨分水阀。合法配置空间仅数百至上千种。
- **穷举主场在 Scala**：步进规则的唯一实现住在 `inner/dial/`，编纂期由 Scala 测试规范**穷举该盘族全部合法配置**——与 `mandate-slice-v1.json` 同构（实测方生成契约、他栈回放核对），不做跨栈双实现。逐条断言：
  1. **CSP 有解的配置 ⟹ 离散动力学在 `N_max` 步（如 60 步）内单调锁相收敛**——无伪吸引子；
  2. **无解配置 ⟹ 在 `M_max` 步内进入可检测的周期环**——离散确定性有限状态机必然入环，盘面状态哈希重复即判定入环，仪器**主动宣告阻挫**，而非让玩家对着永远打颤的指针猜测；
  3. **逐拍对表**：GH 步进呈现器的每拍盘面状态哈希须落在契约轨迹上，偏离即实现 bug。
- **门槛诚实条款**：断言 1 是整个仪器层的**存在性假设，不是既定事实**——伪吸引子是弛豫式求解器的默认行为而非边角病灶。§9.1 最小原型**先证后建**：若穷举实测**证伪**（存在有解而不收敛的配置），退回**机械枚举兜底方案**——曲柄 = 里程表进位计数器，逐槽试闪、撞弧即进位，有限空间内健全性免费；届时 §3.3 弛豫叙事与 §6 自激条款需联动改写。原型跑通之前，§3.3 的行为描述一律按「表现层剧本」理解。
- 验证产物固化为 **`contracts/dial-board-v1.json`**（与 `mandate-slice-v1.json` 平级）：盘族定义 + 逐配置存活集/收敛/入环界限 + §6 违规配置的受控自激行为表。契约 schema 只描述盘族（槽道、孔位、元件、界限），**不含任何山体语义**——24 候选只是这份通用契约的一个生成来源。Scala 运行时按契约查表驱动全部读数（存活集、水柱、辉光、阻挫宣告），**零运行时判官**；「仪器永不撒谎」由契约保证，不押注动力学运气。Elixir `voy.content lint` 回放契约，并核对候选空间可归约为「钉值 + `==` + `neq`」三词表达、实装题目解唯一——表达力不够或解不唯一即内容错误，编译期拦下。
- 手感纪律：1980s 地质仪器的乐趣在于「摸清一台老仪器的脾气」，而非自由飞线的布线内卷；制式黑盒形态（铸铁/胶木外壳、固定槽道、铭牌批号）同时是叙事资产。

## 5. 玩法闭环与读数单源

### 5.1 标准主循环（五段式）

> **① 现场验山**（钟表/指南针测出此刻山体的漂移相位与滞后，札记 07 §5 第 2 条）
> → **② 钉针入盘**（实测相位 + Hop 1–4 卷宗证据作为定针插进盘缘，未知槽放入菌苞游核）
> → **③ 手摇指认**（转动曲柄激发压电闪光：同相电弧烧缩矛盾支路，菌苞游核滑入唯一驻波槽、菌丝长满搭桥，指认隐藏因果并锁死针对「此刻山体」的 `safe_tick` 相位处方）
> → **④ 合闸镇山**（拉下合闸杆，盘缘发射水晶在解出的 `safe_tick` 窗口向真实区块 `MandateRuntime` 投递 `FirePulse`，抵抗 E4/E4b 漂移或完成 `c0` 重锚）
> → **⑤ 大山阅卷**（慢速 FHN 连续场接收脉冲，演算沉滞庇护或结局跃迁）。

山的周期随慢变量漂移（`PhaseResponse` 周期动态重算），因此盘的解永远是**针对此刻之山的处方**——验山永远是第一步；推理是静态的，验收是动力学的（E4/E4b 抵抗是真实考试，不是剧场）。

### 5.2 候选灭绝读数：单一来源 = 契约

通用组件只暴露**各变量的存活域**（与山无关的通用 CSP 信息）；物品层把它解释为 24 候选世界的存活集——检视水柱物理上对应 `Ascribe` 的关键归因维度（源头频段、阻尼完好度等）。**存活集只有一份逻辑**：编纂期由约束传播算出、固化进盘契约，运行时按（配置 × 已插定针 × 拍数）查表投影到水柱/辉光；GH 支路的缩菌熄灭是这份查表结果的动画，不是另一份会漂移的逻辑。插第 1、第 2 根定针（Hop 1–2 证据）并摇动曲柄时，违反该证据的支路当场缩菌熄灭，玩家肉眼可见候选集从 24 缩减到 6、再到唯一亮起的菌丝驻波回路。杜绝「灵异分歧」的方式不是祈祷两份逻辑恰好一致，而是**根本没有第二份逻辑**。

## 6. FORCEDENTRY 保留条款：操作规程即攻击面（脱手自转的赛博格苏醒）

限定盘族反而成全了「越界自举」的高光时刻——自由拓扑没有破解感（系统本来就允许乱连），**唯有制式仪器才有真正的 Exploit**：

- 《制式验山盘操作规程》规定：「外圈孔位仅限定针（输入观测），中心孔位放置菌苞游核（手摇读取解），**严禁反插或跨槽短接，以免引发活菌-压电回波自激**」。「严禁」二字即最诱人的漏洞通告。
- 前中期玩家按规程把盘当被动的手摇推理表（摇一下走一步）查 24 候选真凶；后期要逆转 `:open` 山谷结局时，依 jar 内 `.ex` 手稿（或 Hop 4 卷宗）的暗示**故意违规**——在边界孔塞进菌苞游核、或将分水桥反相卡进抵消窗死区——触发预设的**受控自激振荡（驻波自举）**：盘内紫晶压电闪光喂养菌丝、菌丝节律收缩反过来拽动棘轮敲击紫晶！**玩家松开手后，盘侧的手摇曲柄竟自己跟着大山的脉搏咔哒、咔哒地空转打闪起来**，死仪器彻底苏醒为一台半生物半机械的**自动锁相脉冲发射机**（即体外自适应起搏器，自动维持沉滞庇护 / 抵抗 E4/E4b，衔接札记 08 §2.4 自动化心跳的涌现位）。
- 两层诚实：diegetic 层面这对水文队是真实的 FORCEDENTRY（他们没料到自己的滤波算子被组合成状态机）；extra-diegetic 层面这是**被设计好的秘密机制**——违规配置同属限定盘族的有限状态集，全部经 §4.2 盘契约穷举验证，运行时按契约查表，绝无恶性 bug。游戏里的「破解」必须是设计者想到、但让玩家以为是玩家想到的。
- 叙事焊接：水工队当年仿卢基扬诺夫机修涵洞、埋测压管、架压电换能器，本只想造一台「以山测山」的线性渗流计算机；菌网滞后（`M` = 记忆元件）与铜钲抵消窗（`c0` = 非线性时序门）混入管网后，线性积分器跨过通用性阈值，自举为带记忆与自维持闭环的**地质级寄生状态机**——快脉冲改写慢介质阻抗（信号改写 plumbing 本身）即是那台机器的「自修改时刻」。**他们以为自己在接管子，其实是在流片。** jar 内 `.ex` 源码即技术员试图用逻辑语言形式化这台失控机器的遗物手稿。

## 7. 工程边界与接线现状

- **不动**：四维 RK4 方程、`mandate-slice-v1.json` 数值契约、`Regime`/`PhaseReading` 枚举名。盘内离散元胞为全新独立小实例，落于 **`inner/dial/`**（通用组件，不绑 `ChunkPos`、不 import Mandate/Minecraft，循 `MandateGrid.CellCoord` 抽象整数对先例），`inner/` 纯度不破；山只在物品绑定层（验山读数 → 定针、合闸 → `FirePulse`）出现。
- **复用**：拓扑增删走 `EventDTO` 的 `AddLink` / `RemoveLink`（札记 07 §6 已预留）；盘面状态随 `MandateSnapshot` 思路持久化；水晶薄桥的 `FirePulse` 走现有协议（发射器闭枚举纪律不破，札记 07 §1）。
- **分层纪律**：红石只碰**信号层**（水晶换能、盘面时序）；**功率层**（涵管/分水堰/节流阀改写 `LatticeEdge` 扩散/平流系数与局部 `c0`）属后续札记范畴，本札记不含。
- **真理分布**：编纂层（Elixir）生成候选空间；穷举主场在 Scala（步进规则唯一实现，实测生成盘契约）；**盘契约是仪器侧唯一真理层**，盘面 GH 动力学是它的物理表现层（逐拍对表，§4.2 断言 3）；本体层（大山 FHN）是验收层。Scala 运行时无判官、无隐藏逻辑。

## 8. 四条设计铁律（动工纲领）

1. **无方向性（Relational Directionlessness）是核心玩点**：孔位平等，定针即输入、游核即未知数；正向推演与反向溯因共用同一块盘、同一套导轨——方向在查询时涌现，不刻在仪器上。
2. **极简离散物理**：绝不碰连续 ODE 数值契约；盘内只有三态元胞（`0 / 1 / R..1`）与两条原语（同相牵引、同相互耗）。
3. **廉价而有信息量的失败**：支路冲突只熄辉光/跌水柱，不毁元器件；「支路暗下 = 候选被否证」；无解必在 `M_max` 内可判定地宣告阻挫（契约断言），**仪器永不撒谎**。
4. **永不暴露门**：盘面 3~5 核小尺寸；词表只用定针/游核/分水桥/对时/合闸/验山；反馈只用辉光呼吸、水柱高低、指针偏摆、铜音节拍——不出现任何数字电路符号。
