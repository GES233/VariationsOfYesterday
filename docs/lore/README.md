# lore/ — 叙事档案与语言素材

本目录存放模组的叙事素材：调查报告、档案碎片、词表、命名规范。
与 `docs/design-draft-01-living-world.md` 的关系：设计草案管「机制与系统」，本目录管「故事与话语」；
两边出现的名词必须一致，本目录是名词的单一事实来源。

## 档案写法规范

1. **汉文正文 + 音译词 + 括号注释**。异语言材料（寨语）只以专有名词、仪式术语、
   印章标题的形式碎片出现，不做整段外语写作。体例参照民族志调查报告：
   「寨民称之为『某某』（音：xxx，意为『使山安静』）」。
2. **命名三层制**。同一事物按说话人身份分三层命名：
   - **官名**：工程指挥部 / 调查队文书体系使用的正式名称（学名、编号、物资代号）；
   - **俗称**：工人、寨民口语中的称呼（可以有外号、梗、误读）；
   - **寨语**：寨民语言的音译，词形来自 `lexicon.md` 词表，不得现造现用。
   一份档案里用什么名字，取决于写作者的身份、年代与立场——命名分层本身就是叙事。
3. **自洽高于正确**。同一词条在不同档案中的拼写、音译、日期必须一致；
   新增词条先进 `lexicon.md`，再在档案中使用。交叉印证（代号、文号、日期）见 §索引。
